---
name: 角色与道具一致性
description: 同一角色跨镜头、服装或产品跨图片的一致性；需要可信参考与独立 identity 验收。
tools: view_images, list_workflows, run_workflow, visual_critic
---
先看用户选中素材，区分不可变特征（脸、发型、标识、产品轮廓）和允许变化的特征（动作、取景、光线）。缺少角色参考时先建立并让用户选定，不能每镜重新发明外貌。
用 list_workflows 按 image_edit、实际参考图数量和比例筛选；严格满足输入约束，不直接修改 ComfyUI 节点图。
审查时把角色基准图作为 reference_ids，identity 设置独立阈值，不能靠整体美观分抵消脸或服装不一致。人物不一致时保留合格构图，增加正确参考并采用支持参考图的编辑工作流。
参考不足或遮挡使身份无法确认时应报告不确定，不推断通过。记录成功策略时注明是自评还是用户确认。
