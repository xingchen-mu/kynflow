# 角色与道具一致性

## 输入与锁定项
适用于同一人物、服装或产品跨图、跨镜头复用。用 view_images 看真实参考，不从节点标题推断外貌。建立简短资产卡：基准节点、可见识别特征、允许变化、当前剧情状态与看不清的部位。

人物核对脸型、发际线、发型轮廓、服装剪裁与配饰；产品核对外形比例、接口/瓶盖、颜色与标志位置。动作、表情、机位通常可变；伤口、湿衣、持物等由剧情状态决定，不能一概永久锁死。缺基准时先制作候选让用户选定；背面或侧面未提供时，注明补充设计仍需确认。

## 按失败选择策略
| 情况 | 做法 |
| --- | --- |
| 同一造型只换动作或背景 | 参考图编辑，明确保留身份与服装，分开描述变化 |
| 用户主动换衣服 | 锁脸与发型，更新服装资产卡；旧服装不能继续当硬约束 |
| 多人串脸 | 给每个人稳定名称、参考用途和屏幕位置，按工作流支持的参考数量提交 |
| 人物太小或被遮挡 | 用 crop_image 看局部；没有足够像素则标记不可判，不能靠想象确认 |
| 跨镜道具无故换手/消失 | 使用 shot-continuity 检查状态链，重新生成必要的承接镜头 |

## 执行与验收
用 list_workflows 查 image_edit 及参考图约束，再用 run_workflow；超过输入数时选择关键参考或拆分任务，不假装全部已送入模型。每轮都保留原基准，避免只参考上一代输出造成身份漂移。

visual_critic 的 reference_ids 传入明确的身份参考，最多 4 张；需要比较相邻镜头时选取必要参考，其他分次审查。identity 条件分别写脸型、发型、服装或产品部件，不能以单一「像同一个人」掩盖硬错误。spatial 检查站位，视频的 temporal 检查漂移；静态图不能提交 temporal。

## 输出与修复
输出资产卡、生成节点和逐项一致性结论，标记不可观察项。局部失真时保留合格布局并补正确参考；姿势和脸都失败时先修基准/关键帧，再重做视频，不靠更长的否定词串修复。记录经验时区分助手自评与真实用户确认。
