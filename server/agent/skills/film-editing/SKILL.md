# 视频剪辑与成片

## 输入与工具边界
输入已完成的视频节点、顺序/叙事意图、目标时长、对白原文、字幕偏好和必要动作。本技能处理选段与硬切成片；assemble_video 保留原音轨、支持对白音量处理和字幕，不能据此承诺配乐、多轨混音、L/J 音频跨镜、复杂转场或调色。

## 选择剪辑点
1. 用 inspect_clips 读取实际时长和明显声音区间；区间是声学检测，不是转写，也不能证明那句台词真的说对了。
2. 用 view_video_frames 在起止、动作完成、切点附近抽帧。按信息功能选段，先保证台词和必要动作完整，再压缩等待和重复；不能只按分镜理想秒数裁切。
3. 连续动作切在有明确承接的阶段；空间变化靠已设计的建立镜头交代。需要反应时间时保留停顿，不强求所有镜头等长或都很快。
4. 若用户时长容不下完整台词与动作，列出可压缩项与实际差额，不能默默剪掉原台词。

## 执行与输出
用 assemble_video 的 clips 指定顺序和 start/end，单位是原片段中的秒。lines 写台词原文；精确 from/to 也是原片段时间，不是成片累计时间。subtitles=false 表示不烧字，不能误当成删除对白。缺少已核对的台词原文时先核对，不用臆造的 lines 绕过有声片段检查。

出现切掉明显声音或首帧不匹配的错误，先核查选段、台词与实际首帧；仅确认该段本来就不是从关键帧开始时才使用 skip_first_frame_check，不能把它当常规绕过选项。

输出片段选用表、成片节点、实际时长、字幕/声音处理与待人工核对项。有清楚身份或产品参考时一并保留用于审查。

## 验收与修复
visual_critic 对成片做 temporal、composition、text 等检查，identity 需真实参考。工具只采首中尾，长片需额外检查各切点；抽帧不能证明音质、口型或每个字幕的时序，应如实记录证据边界。

整片质量条件不能因抽样好看而通过；scope 的限定与全片要求如何区分，按需读 shot-continuity。用户确认播放结果可作为补充证据，助手不能代填用户已确认。

台词截断：扩选原片段；字幕错位：核对原片段时间；节奏拖沓：删重复信息；动作接不上：先找正确切点，素材不存在才重做镜头。声学检测误把环境声当对白时说明限制，不编假台词。
