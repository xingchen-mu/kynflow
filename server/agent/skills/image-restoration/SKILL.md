# 图像修复

## 输入与诊断
用 view_images 查看原图，记录缺陷的位置、范围、可恢复信息与用户主动要改的内容。默认保留人物身份、文字、年代特征、构图和原有颗粒。修复划痕、上色、现代化妆和换背景是不同目标，不能顺带改变。

| 缺陷/目标 | 优先能力 | 不能据此宣称 |
| --- | --- | --- |
| 局部划痕、污点、破损 | inpaint，有明确蒙版与周边上下文 | 恢复了缺失区域的历史真实细节 |
| 仅尺寸不足 | upscale，保留画面语义 | 凭放大找回原本不存在的字或五官 |
| 全局褪色、偏色 | 已安装的相应校正工作流 | 已完成可测量的色彩校准 |
| 去背景 | remove_background，检查头发与透明边缘 | 得到了完整、无瑕的透明轮廓 |
| 重建大量缺失内容 | image_edit，明确推测部分 | 新生成内容就是原貌 |

## 执行
用 list_workflows 检查能力、参考与蒙版输入，再用 run_workflow。工具不能提供所需蒙版时，引导用户进入已有局部编辑器；不能以全图重生代替局部修复。先修复，再按需求放大；原图节点保留作对照。

人脸与文字区域先用 crop_image 看清；裁剪只用于检查或合适的编辑工作流，不能假设存在自动回贴工具。多种缺陷分步处理，每步仅修当前问题，避免锐化、去噪、磨皮同时过量。

## 输出、验收与修复
输出缺陷清单、处理范围、结果节点与新增推测。visual_critic 对照原图检查 identity、composition、quality；原文字可读时另设 text。完全缺失的脸或字应标为无法验证，不能打高分通过。

脸变年轻或形状改变：回原图、缩小修复范围；皮肤蜡化：减弱去噪与纹理重建；放大出现假字：保留原信息并标记不可恢复；抠图边缘发白：修边缘，不重生整个人物。审查既看修复处，也看本来完好的区域有没有被改。

## 来源与状态
内容版本 1.0，实验性。能力边界来自 Kynflow 工作流与编辑器契约；缺失细节的不确定性和定向修复方法为本库原创整理，未宣称档案级复原，尚未做真实照片对照评估。
