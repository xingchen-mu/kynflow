# 材质与表面表现

## 输入与判断
输入材质参考、表面加工方式、形状、环境与观看距离。一个物体可有多种材质；先把瓶身、盖、标签或屏幕分别命名，避免整件物体共用一层高光。照片不足以确定材质时说明推测依据。

| 表面 | 应描述的可见特征 | 易错与修复方向 |
| --- | --- | --- |
| 透明玻璃 | 背景可透视、厚边折射、连续边缘与受控反光 | 不透明：调整透射/背景；边缘消失：增加明暗分离 |
| 磨砂玻璃/塑料 | 漫射透光或柔宽高光，边界有厚度 | 被画成清玻璃：明确表面散射与模糊透视 |
| 抛光金属 | 环境反射条带、曲面明暗渐变 | 塑料感：恢复有结构的反射；全黑：提供可见反射面 |
| 拉丝金属 | 有方向的细纹与对应高光 | 镜面化：明确局部加工方向，不给全物体同一纹路 |
| 布料/皮革 | 织纹或皮纹、褶皱、缝线、受力与弯曲 | 石头感：调整柔软度；橡胶感：保留微纹与光泽差 |
| 食物/液体 | 湿润、酥脆、颗粒、黏度或气泡等真实状态 | 塑料光泽：减弱均匀镜面，回到食物特征与侧光 |

这是一份生成画面诊断表，不是物理渲染参数。不能承诺提示词可以设定准确折射率、粗糙度或测量色差。

## 执行与输出
用 view_images 核对基准，输出「部件 → 表面 → 光照响应 → 保留项」。产品专项按需用 read_skill 读取 product-photography 的 references/glass-and-perfume.md、references/metal-and-jewelry.md 或其他对应资源；不把玻璃规则套给所有产品。

只改变失败表面的描述或光源关系，避免换材质时顺带改变产品几何、颜色或标识。若光线问题主导，交给 lighting；产品实际工作流与生成由制作技能负责。

## 验收与修复
visual_critic 用 quality 检查反射、透射、纹理与接触关系；产品保真另用 identity。模型绘出纹理不代表纹理方向、密度或材质符合参考。高光遮字归入 text 条件，不能只评价「金属很亮」。
