# 影视运镜

## 输入与决策
输入首帧、镜头目的、主体动作、目标时长、结束画面和模型能力。先问运动增加了什么信息；画面自身能完成叙事时可固定，不强行加入运动。

| 目的 | 运动选择 | 提示与风险 |
| --- | --- | --- |
| 强调发现或情绪 | 缓慢小幅推近 | 写出起始到结束景别，不能只让人物变大变形 |
| 揭示更大环境 | 拉远 | 结束必须出现的新信息需有设计，避免凭空长出场景 |
| 展示横向空间 | 横移或摇摄 | 横移有相对视差，摇摄是原地转向，两者不混写 |
| 跟随移动主体 | 跟拍 | 分开写主体方向、相机方向和相对距离 |
| 展示产品侧面 | 有限角度环绕 | 背面未知、标签和几何易漂移，先查参考是否足够 |
| 快动作、精确标签、复杂交接 | 固定或减小运动幅度 | 把生成预算留给主体动作和识别信息 |

推拉移动相机，变焦改变视角范围，不能视作同一控制。生成模型只可能近似这些视觉效果，不能把摄影术语当成确定的轨迹参数。

## 执行与输出
输出「起始构图 → 相机路径/方向/速度 → 主体动作 → 结束构图 → 必须保持的身份/几何」。若动作为开盖、转身、递物，写清先后及能否在可用时长内完成。复杂主体动作与大幅环绕同时失败时优先拆解或简化，不默认加更多运镜词。

H3 用 read_guide 读 short_drama 的 video，其他模型查实际工作流。首帧无法表达结束状态、能力不支持尾帧控制时，说明限制，不假装文字等同于已传尾帧。

## 验收与修复
visual_critic 用 temporal 检查抽样中的起止与漂移，identity 对照真实参考。view_video_frames 在动作转折、遮挡和镜头末尾附近增加样本；仍不能证明全片无抖动或闪烁。

相机不动：确认主体动作是否被误写成运镜；画面变形：缩小角度/速度，先保住关键帧；结尾出画：限定结束构图。输出节点、观察到的路径、未覆盖时间与重试理由。
