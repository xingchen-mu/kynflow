# 构图与视觉层级

## 输入与决策
输入交付比例、观看尺寸、信息优先级、参考和不能裁切的内容。先回答观众首先看什么、随后看什么，再选择布局。构图指导不代替字体排版或精确印刷设计。

| 任务 | 布局策略 | 需要验证 |
| --- | --- | --- |
| 单品识别/电商图 | 主体占足够面积，必要部件完整入画 | 缩小观看仍能识别，边缘不贴切 |
| 产品海报有文案 | 主体与文字区分离，留白中减少高对比细节 | 所需行数放得下，不盖标签 |
| 关系或对话镜头 | 人物面向与视线有目标，按信息分配空间 | 人物左右、视线和遮挡可解释 |
| 对称、秩序与仪式 | 中心/对称布局 | 重心稳定，不能机械套三分法 |
| 环境叙事 | 保留有意义地标，控制前中后景层次 | 环境提供信息，主体不被淹没 |

明度对比、饱和度、面积、清晰度都会改变视觉权重。留白是功能区域，不要求一定白色；虚化背景也可能有抢眼亮斑。主体太小先放大/裁切或简化背景，不靠「突出主体」四个字。

## 执行与输出
用 view_images 看素材与预期裁切。输出文字布局：主体区域、辅助区域、文案区、视线/动作方向、不可裁切部件及预期阅读顺序。用画面左/右描述；必要时用 mark_layout 把关系画成布局参考。多比例版本逐一重新检查，不能把横版中央裁切视作竖版完成。

## 验收与修复
用 visual_critic 的 composition 检查尺度、重心、留白和裁切，spatial 检查人物/道具关系，文字另用 text。构图通过不代表产品身份、拼写或材质通过。

文案区杂乱：移动装饰或降低该区对比；头顶太挤：重取景，不随意缩脸；道具喧宾夺主：减小面积/对比或删掉；人物视线出画：在叙事允许时重留空间。保留用户主动选择的偏心、极端留白或裁切，按意图验收。
