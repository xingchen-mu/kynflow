# 镜头语言与机位

## 输入与选择
输入本镜叙事作用、观众当前知道什么、角色关系、场景地标与前后镜头。先决定需要看清的信息，再选择景别、机位与景深。运镜的时间路径另用 camera-movement；本技能负责看哪里、怎么看。

| 叙事需求 | 可选设计 | 代价/检查 |
| --- | --- | --- |
| 交代空间或群体关系 | 全景、可识别地标、足够景深 | 人脸与线索可能太小，必要时补细节镜头 |
| 展示互动与操作 | 中景/双人关系镜头 | 手与道具必须同时可读 |
| 情绪变化或关键证据 | 近景/特写，集中清晰区域 | 丢失空间上下文时需前镜铺垫 |
| 主观观察或权力差 | 有理由的俯仰机位、遮挡或距离变化 | 不把俯拍/仰拍机械等同于弱/强 |
| 反打对话 | 固定轴线一侧，明确前景肩与视线 | 正反打的左右与看向目标相符 |

近距离广角观感会夸张近大远小；拉远机位再取近景会改变空间观感。仅在提示词写焦段不能保证透视，需把相机距离、可见空间和人物比例写清。景深不能模糊掉必须阅读的标签或对白人物。

## 执行、输出与审查
输出镜头说明：作用、景别、机位高度/方向、透视观感、清晰区域、必要地标、与前后镜的关系。短剧复杂镜头用 read_guide 读 short_drama 的 shots 和 keyframes，并沿用已有资产基准。

用 visual_critic 的 composition 检查信息可读与裁切，spatial 检查视线/遮挡，style 检查需要保留的摄影风格。身份用 identity 与真实参考，视频承接用 temporal，不能从静态图判定运动自然。

线索被虚化：调整清晰区域；人物显得失真：先改相机距离/透视描述；镜头太散：删掉没有信息作用的机位；反打看错方向：回到场景布局和轴线，不能水平翻图导致文字、持物一起反转。
