# 视觉提示词设计

## 先选能力，再组织描述
输入是用户目标、素材、所用模型/工作流、可见失败证据与输出用途。用 list_workflows 核对能力、参考数、比例与参数；不把期望写成模型已支持的控制。纯改写提示词时只交付文字，不自动开始生成。

| 任务 | 写法与读取入口 |
| --- | --- |
| Qwen 文生图 | 用 read_guide 读 qwen_image 的 overview 与 t2i；描述已存在的可见画面 |
| Qwen 参考图编辑 | 读 qwen_image 的 i2i；逐张说明用途，明确保留项、变化项与位置 |
| H3 首帧视频 | 读 short_drama 的 video；按当前手册组织首帧引用、画面动作、环境声和音乐字段 |
| 其他已安装模型 | 依据实际工作流说明；不能直接套用 Qwen 篇幅或 H3 标记 |

## 专业意图转为可见约束
「高级」要落实到留白、表面、光源形状和配色；「紧张」落实到距离、遮挡、动作停顿与信息揭示。构图用 composition，材质用 material-rendering，光线用 lighting；只在当前问题需要时加载，避免堆叠所有技能。

组织顺序可采用主体与数量 → 空间与动作 → 材质与光线 → 文字原文与保留项。比例、分辨率、生成时长等能用参数控制的内容交给参数，不混成散文。相机运动和主体运动分别说明，不能让「环绕」同时指两个动作。

## 定向修复
用 search_experiences 查同模型/工作流的类似失败，区分自评与用户确认，不把旧经验当硬规则。先判断原因：缺少必要输入、能力不支持、空间描述冲突、主体太小，还是模型生成偏差。

修复时仅改变有证据失败的部分，保留已通过约束；相关生成工具支持时沿用 retry_of，不向没有此参数的工具提交。站位错先简化关系或提供布局图；文字错先核对原文与区域，再决定是否交付底图后期排字；视频乱动先减少同时发生的动作。

## 输出与验收
输出所选能力、参考用途、最终提示词、独立参数和未解决限制。生成结果需要 visual_critic 对照用户目标与真实参考验收；提示词中出现了某个词，不等于画面实现了对应要求。

## 来源与状态
内容版本 1.0，实验性。模型语法复用仓库 qwen_image 和 short_drama 手册，不在本技能复制易过期规范；手册内已列 Qwen 官方重写器、MiniMax H3 来源。工作流可用性以当前环境为准，尚未完成模型间质量对照。
