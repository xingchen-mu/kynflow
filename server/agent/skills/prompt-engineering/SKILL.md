---
name: 视觉提示词设计
description: 为图片、参考图编辑和视频编写或修复提示词；根据所选模型与失败维度调整。
tools: read_guide, list_workflows, search_experiences
---
先确定任务与工作流能力，再写提示词；不要写模型无法接收的参考图或时序控制。Qwen 图片先读 qwen_image 手册，H3 视频先读 short_drama 的视频部分。
描述可见主体、动作、空间关系、景别、光线、材质和文字原文。参考图逐张说明用途；编辑指令同时明确需要保留与改变的内容。
检索类似失败的经验，优先采用用户确认有效的修复。每次重试只针对具体失败改变策略，保留已通过约束，并沿用 retry_of。
提示词不是验收证据。生成后由 visual_critic 对照任务和参考图判断，不能以「提示词已写到」为由认定画面满足要求。
