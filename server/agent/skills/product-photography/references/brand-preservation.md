# 品牌与标签保留

区分真实商品还原、允许改包装的设计提案、没有品牌资产的概念图。只有第一类默认把原包装与文字视为硬约束；用户主动改设计时按新要求更新锁定项。

记录基准节点、产品轮廓、各部件颜色、标志位置、标签原文、字体外观、文字方向和不可遮挡区。低清、遮挡或背面缺失不等于可以补造；把未知内容列出，必要时索取更清楚参考。

生成与审查均使用真实基准，不能只拿上一版生成图做「原产品」。多轮修改留一条到真实参考的关系。标签小到看不清时用 crop_image 看局部，或请求更大素材；不能从模糊字形猜成常见品牌。

验收将每项独立列出：外形 identity、颜色/部件 identity、标签 text、文案区 composition。品牌文字不能靠平均分抵消。原图字体可辨而输出不可辨时不通过；原图本身不可辨时记录不可验证。

精确排字失败，可交付已通过的产品底图并列出外部排字要求。若现有工作流没有叠字、合成或字体控制，不能描述为已经做完。后期方案也需用户实际拥有的文字/标志素材，不能顺便编造认证、产地或功效。

本页来自 Kynflow 的参考图与独立审查工具约束，为原创操作规范；不是外部品牌授权判断。评估状态见 [来源记录](sources.md)。
