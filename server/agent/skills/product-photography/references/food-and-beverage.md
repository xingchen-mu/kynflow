# 食品与饮料

先确定食物形态、份量、配料、容器和状态：热/冷、完整/切开、干燥/湿润、刚出炉/融化中。没有依据时不增加配料，不把创意食物图当作实物包装证明。

| 对象 | 设计起点 | 核对 |
| --- | --- | --- |
| 扁平摆盘、餐盒、包装组合 | 俯拍可交代分区与数量 | 不能遮住关键内容与标志 |
| 汉堡、蛋糕等层叠形态 | 低一点的斜角交代层次与高度 | 比例、层数、接触与重力 |
| 酥皮、烤物、切面 | 柔和侧光保留纹理，背景克制 | 酥脆与油润分区，不涂一层塑料亮面 |
| 透明饮品 | 侧后光显示透光、杯沿与液色 | 液面、冰块、气泡和杯壁关系 |

蒸汽、结露、滴落是状态信息：热菜的蒸汽和冰饮的冷凝不能无缘无故同时出现；多镜视频里的冰量、咬痕和液面要进入状态链。

用贴近用户用途的道具和场景，不用高饱和滤镜掩盖食物色偏。饱和度和白平衡影响食欲观感，但肉眼看着好看不能证明实际颜色准确。

审查 identity 检查具体商品/包装，instruction 检查配料和数量，quality 检查形态、质感与接触。修复时先纠正食物状态和光线，再调整道具。来源见 [来源记录](sources.md)；角度表与状态规则为原创方案，尚未实测。
