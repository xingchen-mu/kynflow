# 化妆品与护肤品

输入需区分外包装、瓶/管、盖/泵头、透明窗、膏体或色料。先锁定色号、容量文字、包装形状、印刷层级，不能把粉底色号改成更「好看」的颜色。

- 不透明柔面包装：宽柔高光与轻阴影展示体积；避免把管身画成玻璃。
- 透明精华瓶：先按玻璃规则确定透光与液面，再处理瓶盖；不要让滴管无故穿过瓶底。
- 金属盖或泵头：独立设置反射，与磨砂瓶身区分；检查出液口朝向和部件数。
- 膏霜、口红、粉饼：用可见表面和状态表现质地，不能把油润、粉质、哑光混成同一层镜面。
- 海报：为用户文案留区域，产品标签与后期标题分开；不把「抗衰」「临床认证」当默认装饰文案。

试色、抹痕和液滴只有在用户提供依据或同意概念化时加入。它们展示的是视觉方案，不能证明真实肤感、配方或功效。

验收按部件几何/色号 identity、标签 text、表面与接触 quality、文案留白 composition 分开。盖子变形先修几何，色号偏移先锁原色与光照，不重做所有背景。

本页为原创应用方案，未做真实化妆品评估；基础来源与许可见 [来源记录](sources.md)。
