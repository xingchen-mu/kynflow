# 数码与电子产品

先记录外壳比例、屏幕边框、按键、镜头、接口、转轴、接缝、通风孔与标志；看不清的型号细节写未知。耳机左右、键帽布局、手机镜头数量不能随构图改变。

正面适合界面与识别；轻微三分之四视角适合展示厚度与结构；背面、接口特写需要对应参考。不要为了「科技感」给封闭外壳增加无依据的透明结构或发光电路。

屏幕内容单独规定用途和文字原文，避免反光遮挡必要信息；屏幕、金属框、塑料壳分别描述光泽。产品放在桌面时核对接触阴影、支撑点、线缆接头和受力方向。

界面或键盘需要精确文字时，优先保留真实素材/可用编辑流程；没有叠图能力就明确需外部后期，不能声称工具已经换屏。生成的接口、屏幕读数与性能表现不能作为真实功能演示证据。

identity 检查结构，text 检查屏幕与标志，quality 检查反射和接触。接口错先回真实参考，不靠「精密科技」重试；屏幕可读但外壳变形仍不通过。

本页为原创产品诊断方案，尚未实测；基础摄影来源见 [来源记录](sources.md)。
