# 产品布光与构图选择

用于白底主图或尚未确定具体光型的主视觉。以下是生成画面的设计说明，不是灯具或渲染参数。

| 用途 | 设计起点 | 需要避开的代价 |
| --- | --- | --- |
| 白底识别 | 干净背景、完整产品、柔和主光、适量补暗，底部有轻接触阴影 | 背景过亮吞掉透明边缘；补光过平看不出形状 |
| 暗调主视觉 | 深背景，侧后光或反射条带分离轮廓，标签区保持可读 | 通体发黑；用一圈自发光代替真实边缘 |
| 纹理细节 | 斜向光或侧光、足够大取景，背景退让 | 纹理比商品本身更强；局部微距误改比例 |
| 带文案海报 | 主体与文案区错开，文案区少高对比边缘 | 装饰挤满留白；产品缩到无法识别 |

先确定相机高度与产品朝向，再画出一条可解释的主光与阴影关系。地面反射不应让商品像两件；除明确悬浮创意外，应有可信接触点。布光和风格变化不能改包装固有色。

交付前缩小查看识别，再放大看标签和边缘；逐项核对文案区、部件裁切与反光覆盖。颜色只能做视觉相似审查，未经管理的生成与显示链路不能证明准确色号。

来源与许可见 [来源记录](sources.md)；细化光线或布局时分别用 lighting、composition，不重复把通用教程塞进拍摄提示词。
