# 玻璃与香水

关键词：透明边缘、瓶壁厚度、液面、透射、标签、焦散。先从参考确定瓶型、肩部、底部厚边、盖体比例、液体颜色/高度与标签位置。没有可见背面时不设计成「精确 360 度商品还原」。

## 选光型
- 亮背景、暗边：适合清晰目录感；让透明体与背景有边界，保留瓶底和侧壁的暗边线。不要把整个瓶体抠成透明轮廓空壳。
- 暗背景、亮边：适合低调主视觉；用侧后方受控长条亮面勾形，正面标签单独保留可读层次。不能让白色条带穿过所有文字。
- 透光展示液色：侧后/逆光可作为设计起点；核对液体内部与背景亮度，避免一整瓶变成不透明发光块。
- 焦散创意：只有当光源、透明体与承接面关系合理时加入，作为辅助；不能遮住产品、生成第二个瓶影或改变瓶底形状。

## 镜头与道具
正面或轻微三分之四视角利于标签识别；过低机位可能让瓶盖遮挡肩部，过广角会夸大底座。道具服务定位，植物、花或果实不能被自动解释成真实配方。蒸汽、水滴、烟雾是可选创意，用户未要求时不默认覆盖标签。

## 失败定位
瓶体像塑料：检查边缘厚度、背景透射与高光形状；双层瓶口：回到原参考与几何；液面倾斜但瓶身直立：修液体状态；标签镜像：修文字和参考用途；焦散不合理：先去掉辅助效果，保留合格瓶身。

审查用原产品检查 identity，用 quality 检查边缘、透射、接触和液面，用 text 检查标签。透明材质规则是待真实生成验证的设计假设，不能据此宣称光学准确。来源见 [来源记录](sources.md)。
