# 金属、珠宝与手表

先区分抛光、拉丝、镀层、石材与玻璃表镜，分别记录。核对表盘布局、刻度、表冠位置、链节、爪镶数量与产品轮廓；不可凭「珠宝」自行增加钻石或刻字。

## 决策
| 表面/用途 | 设计选择 | 应见结果 |
| --- | --- | --- |
| 抛光金属 | 用宽窄有组织的反射面和明暗渐变解释曲率 | 看出曲面而非纯白/纯黑一片 |
| 拉丝面 | 光线与纹路配合，保持加工方向和细纹尺度 | 与相邻镜面部件有区别 |
| 宝石 | 少量局部亮点，保留切面轮廓与本体颜色 | 不变成白色发光球，不靠满屏星芒 |
| 表盘/刻字 | 避开正面大面积反光，保留刻度和指针 | 可读取的内容与原参考一致 |

反射方向应随表面曲率变化，不能给圆表壳每个位置贴上相同直条。过度消除反射会让金属像灰塑料；过度锐化会使链条与镶爪变成锯齿。

审查先外观与部件，再材质与文字。几何错先回原参考；高光遮盘先改光位/反射面；宝石炸白先收亮点，不更换石头颜色。无法从参考确认的微雕或宝石参数明确未知。

反射与加工判断为 Kynflow 原创诊断方案，未进行光学或真实产品评估；摄影基础来源见 [来源记录](sources.md)。
