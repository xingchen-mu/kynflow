# 织物与皮革

输入要区分产品结构、面料、表面处理和颜色。包袋记录提手、搭扣、缝线、拉链、标志、底部与折叠方式；服装记录版型、接缝、领口、袖口和花纹位置。

用斜向光作为纹理呈现起点，保留适度阴影；皮革光泽、绒面散射、织物纤维不能统一成塑料表面。褶皱必须与支撑、重力和受力方向相符，软袋不应像石块，硬挺皮包也不应无故塌陷。

主图优先完整外形与结构识别；细节图再看纹理和走线。近景纹理尺度要与产品尺寸一致，不把细织纹夸张成编织绳。颜色和天然纹理差异以参考为准，不能把所有皮革做成相同颗粒。

核对 identity 的结构与印花、quality 的纹理/受力、text 的标志。表面假时先改光线与光泽；缝线或提手数量错时先修结构。不能因纹理「更清楚」而接受产品改款。
