# 分镜与空间连续性

## 输入与镜头职责
先看当前剧本、场景基准、角色与目标时长。用 S01、S02 等稳定编号；镜头删改后不让已生成节点失去对应关系。每镜写明观众获得的新信息、动作或反应；只换角度重复同一信息时，考虑合并。

| 信息需求 | 景别/机位选择 | 必须看清 |
| --- | --- | --- |
| 建立地点、人物关系 | 全景或中远景 | 地标、出入口、双方位置 |
| 对话和动作关系 | 中景或过肩 | 说话者、听者方向与持物 |
| 线索、产品、情绪转折 | 近景或特写 | 关键细节及其上下文，不随意切断必要动作 |

景别服务于信息，不强制每场从全景逐级推近。镜头语言需要细化时用 cinematography；相机路径用 camera-movement；跨镜状态用 shot-continuity。

## 执行与输出格式
用 write_note 留分镜表，每镜记录：编号、场景、用途、目标剪辑时长、景别/机位、站位/视线、动作起始与结束、道具状态、对白/声音、前镜承接与参考节点。生成时长与剪辑时长分开记录，按工具支持的时长生成后裁剪。

可用 [单镜结构](schemas/shot.json) 记录最小数据；它不是生成工具的参数 Schema。复杂动作与较长台词的节拍见 read_guide 的 short_drama/shots。

同一场先定人物连线与相机所在侧，反打不等于把参考图水平翻转。多人、遮挡与交接用 mark_layout 画绝对位置；已有场景的近景可用 crop_image 取景。越轴有明确意图时，安排可见的过线运动或重新建立空间，不能无意左右反转。

## 验收与定向修复
先对分镜做时长、信息、动作与承接自查；生成后用 visual_critic 检查 composition 与 spatial。身份条件传角色基准；视频才用 temporal。参考包括必要的基准、场景和前镜，超过 4 张分次核对。

视线错先写清画面方向和目标；空间错先修场景/布局；动作塞不下先延长或拆镜，不能靠运镜词补救。改了上游结束状态时，仅使依赖该状态的后续镜头失效。
