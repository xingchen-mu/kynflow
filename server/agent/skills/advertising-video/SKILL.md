# 广告视频

## 输入与决策
明确产品参考、受众、平台比例、目标时长、单一主卖点、品牌文字与行动提示。把用户提供的证据和创意表现分开；不编造功效、认证或性能数据。只有静态主图需求时使用 product-photography。

| 目标 | 视觉策略 | 验收重点 |
| --- | --- | --- |
| 让人认出新品 | 尽早给完整外观，最后留清晰产品定帧 | 轮廓、型号、品牌可辨 |
| 解释使用价值 | 展示一个可完成的使用动作及结果 | 动作与卖点有可见因果 |
| 材质与品牌氛围 | 少量细节镜头配完整主视觉；留出识别时间 | 材质、色彩与原产品一致 |

镜头长度由阅读信息、动作和台词决定，不能把任意时长平均分配。15 秒香水示例：0–3 秒以玻璃边缘吸引注意，3–7 秒给全貌，7–11 秒呈现一个有依据的细节，11–15 秒留产品与行动提示；这是可调整的剪辑计划，不代表生成模型支持这些单段时长。

## 分阶段执行
1. 用 write_note 记录创意、逐镜作用、目标剪辑时长与品牌锁定项。分镜阶段按需读 storyboard；产品关键帧阶段读 product-photography。
2. 先验收关键帧，再做视频。涉及 H3 时用 read_guide 读取 short_drama 的 video 节；可生成时长与参考数以当前工具为准。视频提交沿用当前确认卡，已有授权覆盖时不重复索要。
3. 运镜按需读 camera-movement；每镜选择可见的主体动作与相机路径，不能把标签旋转到看不清却仍要求全程可读。batch_generate_videos 只提交已准备好的镜头。
4. 用 visual_critic 对照原产品检验 identity，文字用 text，视频动作与衔接用 temporal。首中尾抽样不足以证明无闪烁；关键动作另用 view_video_frames 查看事件附近。
5. 成片阶段读 film-editing，用 assemble_video 按真实片段时长裁剪、拼接。工具仅支持硬切、已有音轨与字幕处理，调色、配乐和复杂转场须另有可用工作流才承诺执行。

## 输出与修复
输出创意摘要、镜头表、关键帧/视频/成片节点、实际时长与审查局限。品牌、产品比例或文字失败不能由整体美感抵消。

旋转导致产品变形：缩小运镜角度或回到静止产品；卖点看不懂：补清楚动作或结果，而非只加形容词；结尾读不完：优先延长识别镜头、压缩重复镜头。只修失败镜头及其受影响下游。

## 来源与状态
内容版本 1.0，实验性，未做真实广告成片对照。创作流程引用仓库 short_drama 手册及其现有来源声明；剪辑能力以 server/agent/tools.ts 的工具契约为准。新方案与时间示例为 Kynflow 原创，不代表广告效果承诺。
