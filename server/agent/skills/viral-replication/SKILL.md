# 参考视频拆解与复刻

## 输入与观察边界
输入可访问的视频节点、用户自己的素材、保留/替换项、交付阶段。用 read_guide 读取 viral_replication 的 overview 与 analyze；用 view_video_frames 抽帧，出现切点、动作或标签时加采样。没有可读视频时先请用户提供素材，不能根据标题编造逐秒拆解。

## 从结构到改编的决策
| 参考特点 | 提取的结构 | 改编注意 |
| --- | --- | --- |
| 开场强反差 | 先呈现的异常与稍后的解释 | 用用户产品可成立的反差，不移植虚假卖点 |
| 节拍快切 | 信息密度、镜头长短变化与出现顺序 | 先保证新信息可读，再追相同切点 |
| 运镜揭示 | 起始遮挡、结束信息与路径 | 按 camera-movement 验证现有素材和模型可实现性 |
| 特定人物/品牌 | 身份与包装的参考用途 | 明确替换资产，不当作用户已经拥有的基准 |

拆解表逐项分开「看见的事实」「推测」「尚未验证」。单帧不能证明移动方向，声音检测不能证明台词原文或音乐节拍。要求声音复刻而没有可听证据/工具时，列出待核对部分，不补造音效。

## 执行与交付
用 write_note 保存参考时间段、景别、主体、文字、动作、切点、信息功能、观察依据与替换方案。只要分析就停在分析；需要制作时建立参考拆解 → 改编 → 关键帧 → 视频 → 成片依赖。

构图与风格保留项用 composition、style 条件，用户产品/人物用 identity 与真实参考；视频动作使用 temporal。具体生成读 viral_replication 的 references、prompt、generate，验收和修复读 review。视频生成沿用原有授权与确认流程。

输出对照表、改编方案、已完成节点与证据范围。核心动作缺失先修动作和起始状态；节奏不符先修剪辑；品牌误植先改参考用途。拆解表、提示词或稀疏抽帧不能作为整段视听复刻成功的证明。

## 来源与状态
内容版本 1.0，实验性。复用仓库 viral_replication 手册与实际媒体工具契约，方案与决策表为 Kynflow 原创整理。未做真实视频复刻对照，也不保证传播效果。
