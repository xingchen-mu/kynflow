---
name: 参考视频拆解与复刻
description: 分析参考视频的节奏、镜头和视觉结构，并为用户素材设计可执行的复刻方案。
tools: read_guide, view_video_frames, write_note, visual_critic
---
先用 read_guide 查看已有 viral_replication 手册（若无该名字先列手册），对参考视频抽帧并读取可见文字，分清观察事实和推测。
分析开场钩子、镜头长度、信息出现顺序、转场和声音作用。复用结构时结合用户自己的产品与素材，不把参考中的具体品牌或人物身份当成用户资产。
将参考拆解表、改编方案、关键帧、视频和成片建立任务图；节奏、构图、核心动作分别设验收条件。
对照参考审查 composition、style、temporal，品牌或人物素材用 identity。视频抽帧不能证明音效或完整时序；相关要求需要相应媒体工具验证。
