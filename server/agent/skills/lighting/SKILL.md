# 摄影布光

## 输入与光线设计
输入主体材质、背景、用途、参考和要突出的形状/纹理。用 view_images 分清物体固有颜色、镜面反射、透射与阴影；不要把亮面上的环境反射当成印花。

先描述一盏主光：相对画面的方向、高低、表观大小、软硬和色温倾向；再根据暗部可读性决定是否补光，最后决定是否需要背景或轮廓分离。这里是画面设计，不表示可以控制工作流中的真实摄影灯。

## 决策规则
| 需求/问题 | 选择 | 观察结果 |
| --- | --- | --- |
| 清晰展示包装与肤质 | 大面积柔光，适量补光 | 阴影有过渡，标签与脸部细节可读 |
| 表现压纹、织物与食物纹理 | 侧向或斜擦光，保留暗部 | 纹理有微小明暗，不能全部磨平 |
| 深色主体融入深色背景 | 控制背景明度差或边缘反射 | 轮廓可辨，避免一圈无来源发光 |
| 玻璃液体不透明 | 考虑侧后/逆光与背景对比 | 透光与边缘同时成立；另读 material-rendering |
| 正面大反光遮住商标 | 改变光源反射位置、形状或机位 | 标签仍可读，高光不切断识别区域 |
| 同场多镜明暗不连贯 | 固定有动机的主光与背景亮区 | 机位变化后光源仍处于同一场景方位 |

柔光取决于主体所见的光源大小，不能把「柔」等同于「很亮」；高调不等于过曝，低调不等于黑到无细节。不要同时用「均匀无影」与「强烈硬阴影」约束同一主体。

## 执行、输出与修复
输出布光说明：主光、必要补光/遮光、背景分离、预期高光与阴影、必须保留的颜色/文字。将它交给当前制作技能选择工作流与生成，不因读了本技能就自动增加生成任务。

用 visual_critic 的 quality 检查高光、暗部与接触阴影；style 检查与参考的光感关系，商品另设 identity/text。阴影方向冲突先统一主光；表面发白先控制反射/曝光描述；纹理消失先减少正面填充。仅凭视觉不能证明色差、照度或动态范围数值合格。
