# 镜头连续性与状态链

## 输入与承接类型
输入相邻镜头、分镜、角色/产品基准和场景布局。先判断关系：
- 连续动作：承接站位、朝向、姿势、持物、道具数量和环境状态。
- 换场或时间跳跃：仅承接剧情要求持续的伤、衣物、携带物等，重新建立空间。
- 明确重置：按新场景说明，不为连续性添加原作没有的过渡动作。

## 决策与状态记录
每镜记录起始与结束的绝对状态：谁在何地、朝哪、看向谁、哪只手拿什么、道具开闭/数量/液面、伤痕或湿衣、主光来自何处。不能只写「同上」。

| 错误 | 检查 | 修复 |
| --- | --- | --- |
| 人物左右反转、视线不对 | 轴线、机位所在侧、参考是否被镜像 | 修布局或明确越轴过渡，不反转标签与持物 |
| 手机跳手或杯子消失 | 前镜结束到后镜开始是否有交接动作 | 补正确状态，缺失交接需调整相应镜头 |
| 动作跳变/重复 | 前镜结束阶段和后镜动作起点 | 调剪辑点或重做必要动作段 |
| 衣服突然干净、液面恢复 | 是否有剧情理由或时间重置 | 恢复持续状态，不重做无关镜头 |
| 光线换边 | 固定地标与场景光源，而非固定屏幕侧 | 统一世界坐标中的光源关系 |

## 执行与证据
图片用 view_images，视频用 view_video_frames 看切点附近；上一个视频的结尾比最初关键帧更能证明实际结束状态。必要时用 capture_frame 留交接参考。状态链写进分镜或画布文档，任务图只引用相关段落。

visual_critic 的 reference_ids 传角色基准和相邻帧等必要证据，最多 4 张。spatial 核对位置，identity 核对身份和道具，temporal 仅用于视频。每个镜头单独通过不代表两镜剪接连续，切点需成对比较。稀疏抽帧看不清交接时报告不可判。

在支持 scope 的当前工具中，只有任务本来就限定「抽样帧中可观察变化」时，才为 temporal 条件标 sampled_frames；整段无闪烁、完整交接等要求保留 whole_media 并补充相应证据。不能为使审查通过而缩小用户要求，也不能在审查时替换任务图中已经定义的条件。

## 输出与修复范围
输出前后状态表、冲突点、证据时间与受影响镜头。前镜结束状态不变则优先修后镜；前镜改了状态，仅重验使用该状态的下游。不能为了减少返工，把人物真实换手或必要剧情动作删掉。
