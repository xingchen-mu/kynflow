# 产品说明

## 一、报名表用：产品简介（约 300 字，直接复制）

> **Infinode：把一句话变成一条能播的短剧成片。**
>
> 它是一个跑在你自己电脑上的 AI 短剧制片台。写一句故事，它按导演手册一步步做出来：剧本 → 分镜表 → 人物与场景设定图 → 每个镜头的关键帧 → 每个镜头一段视频 → 自动剪辑成片（对白响度统一、中文字幕烧录）。所有生成都交给你自己的 ComfyUI，不经过任何云平台，没有积分、排队和审查。
>
> 每个结果都用一条线连回它的输入，改一版不用重做全片；哪个镜头不满意，只重做那一个。任意 ComfyUI 工作流（导出 API）拖进来就能变成画布上的一键工具，不锁模型。
>
> 它不是"输入一句话、出个东西"：关键帧必须是视频的第 0 秒，审片不过会记录原因并在两次后停下来问你，剪辑前会检查台词有没有被裁掉——这里有一道会说不的工序。
>
> 演示版（预置结果，不连 GPU）：https://37jvsot942shvcu7nwx.traesite.cn
> 完整版（一条命令装在自己机器上）：`npm run dev`

## 二、产品文档正文

### 1. 一句话定位

**Infinode 是一个本地优先的 AI 短剧制片台：从一句故事到一条能播的成片，中间的每一步都可追溯、可单独返工。**

### 2. 它解决什么问题

做 AI 短剧的人现在有两种工具，都不够用：

- **云端生成工具**：积分、排队、内容审查，一个镜头不满意就得重新排；素材和提示词留在别人服务器上。
- **节点式工具**：能生成好看的片段，但交付给你的是**一堆片段**。剧本、分镜、人物一致性、台词、字幕、响度、剪辑，全靠自己在外面拼。

Infinode 补的是中间那一段：**把"片段清单"变成"一条片"**，并且这条片的每一步都留在家里的机器上。

### 3. 核心流程（一句话 → 成片）

1. **故事**：用户给一句故事或一个梗概，助手按题材手册排出节拍、人物和结尾。
2. **分镜表**：每个镜头写清景别、机位、起始画面、动作、结束状态、台词、时长。
3. **设定图**：人物与场景，定死画风句，全片不换。
4. **关键帧**：每个镜头一张，画的是**动作开始之前的那一瞬**。
5. **视频**：以关键帧为首帧，逐镜头生成带声音的片段。
6. **剪辑**：按顺序硬切，对白统一到 -16 LUFS，中文字幕烧录，画面下方。
7. **成片**：放在画布上，连回每一段。

### 4. 关键设计（和"一次性生成"的区别）

| 设计 | 为什么重要 |
|---|---|
| **连线血统** | 每个结果连回它用到的节点：成片 → 每个镜头 → 关键帧 → 设定图 → 分镜 → 那句话。改一版有据可依。 |
| **单镜头返工** | 只重做坏的那一个，其余不动，成片重拼。不用重出全片。 |
| **关键帧即第 0 秒** | 关键帧如果已经把动作画完，视频里人物只能干站着。规则写进助手手册，审片时按这个判。 |
| **审片与重试上限** | 每次审片把结论写回节点（主体不一致/构图错/穿模/动作没做出来…），每个结果最多重做 2 次，用完停下来问用户，不无限抽卡。 |
| **剪辑前查台词** | 台词常落在镜头后半段，按分镜秒数直接裁会把半句切掉。剪辑工具会报告被裁掉的声音区间。 |
| **任务面板** | 所有任务可查、可定位、可取消、可重试；关掉页面再打开还在。 |
| **审批与计划模式** | 批量出视频、删节点前先确认；计划模式下助手只读画布、出方案，你点头才动手。 |

### 5. 技术架构

```
浏览器（React + Zustand）
  无限画布 · 任务面板 · 助手面板 · 工作流编辑器
        │ HTTP / SSE
本地服务（Node + Hono，默认 127.0.0.1:8787）
  ├─ 项目与资产：画布、快照、素材文件
  ├─ 任务队列：排队、进度、取消、失败归因
  ├─ 助手（pi-agent-core）：28 个工具 + 3 本工艺手册 + 记忆 + 审批
  ├─ 工作流：25 个内置模板 + 任意导入的 ComfyUI API JSON
  └─ MCP：把画布能力暴露给外部 agent
        │ HTTP / WebSocket
ComfyUI（本机或 SSH 隧道到远端 GPU）
  Z-Image Turbo · Qwen-Image 2.1 · MiniMax H3 · SeedVR2 · SAM 3.1
```

- 前后端同仓库，`shared/` 放契约，**后端不依赖前端**。
- 助手不直接改节点图：它通过 28 个受控工具操作画布，动作集合里没有"改连线"。
- 剪辑用本机 `ffmpeg`，不传云端。

### 6. 完整版与演示版的差别（必须如实说明）

| | 演示版（公网） | 完整版（本地） |
|---|---|---|
| 生成 | **不生成**，结果为预置素材 | 真实调用本机/远端 ComfyUI |
| 依赖 | 纯静态，2.3 MB | Node 22.19+、ComfyUI、模型文件 |
| 能做什么 | 平移缩放、看成片、点开每个镜头、"试一下"走真实 UI 与进度条 | 全部功能，可出片 |
| 标注 | 顶部常驻「演示模式 · 结果为预置素材，不连接 GPU」 | — |

完整版启动：`npm install && npm run dev`，浏览器打开 `http://localhost:5173`。
生产模式：`npm run build && npm start`，打开 `http://127.0.0.1:8787`。
