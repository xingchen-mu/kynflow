## 四、演示版素材的许可现状（必须原样披露）

### 4.1 当前公网 Demo 的实际素材

`demo/meta.json` 现在记录的仍是上一版画布，产物来自四个模型（按画布里真实发生过的请求统计）：

| 环节 | 模型 | 许可 | 能否商用 |
|---|---|---|---|
| 关键帧/文生图 | Z-Image Turbo | Apache 2.0 | 可以 |
| 换主体、消除、重绘、扩图、抠图 | Qwen-Image 2.1 | Qwen Research License | **不可以**，仅研究评估 |
| 镜头视频 | MiniMax H3 | H3 Community License | 有条件，不覆盖美/欧/英/韩 |
| 超清 | SeedVR2 | Apache 2.0 | 可以 |

也就是说：**当前演示素材里确实用了仅限研究评估的 Qwen-Image 2.1，以及有地区限制的 MiniMax H3。** 这一版尚未替换，原因见 4.3。

另外，旧的 `meta.json` 只写了三个模型，漏了超清用的 SeedVR2。`export:demo` 现在改为从画布每一项的真实请求推导许可（`shared/licenses.ts` 是唯一来源），下一版导出会自动补全，不再依赖手写列表。

### 4.2 新旧素材对比（目标链路全部 Apache 2.0）

| 环节 | 旧素材（当前 demo） | 新素材（重建后） | 许可变化 |
|---|---|---|---|
| 文生图 · 关键帧 | Z-Image Turbo | Z-Image Turbo | 无（本来就可商用） |
| 文生图 · 海报 | Qwen-Image 2.1 | Qwen-Image 2512 | 研究许可 → Apache 2.0 |
| 换主体 / 参考图编辑 | Qwen-Image 2.1 | Qwen-Image-Edit 2511 | 研究许可 → Apache 2.0 |
| 超清 | SeedVR2（旧 meta 漏记） | SeedVR2 | 无，但披露补全 |
| 镜头视频 | MiniMax H3 | Wan 2.2 图生视频 | 地区限制 → Apache 2.0 |
| 消除 / 局部重绘 / 扩图 / 抠图 | Qwen-Image 2.1 | 不在新画布里 | 没有 Apache 等价通道，从演示画布去掉 |

关于最后一行：这四项是内置工具，只接 Qwen-Image 2.1；模板库里没有 Apache 2.0 的等价工作流。重建版把「换主体」的编辑能力交给 Qwen-Image-Edit 2511，其余三项不再出现在演示画布里，而不是换个名字继续用。

### 4.3 为什么这一版还没重跑

- 可商用替换模型没有装在本机 ComfyUI 上：**Qwen-Image-Edit 2511、Qwen-Image 2512、Wan 2.2 图生视频**；已装的只有 Qwen-Image 2.1、MiniMax H3、Z-Image Turbo、SeedVR2。
- 远端 ComfyUI 只开放密码登录，脚本无法自行安装模型。
- 因此本轮**没有生成任何替代素材**，`demo/` 与 `demo/meta.json` 保持原样；不伪造结果。

### 4.4 已准备好的重跑脚本与步骤

脚本：[`scripts/rebuild-demo-commercial.ts`](../scripts/rebuild-demo-commercial.ts)，命令 `npm run demo:rebuild`。

1. 连接 ComfyUI 预检模板所需的模型与节点，**缺任何一个就打印下载清单并以非零码退出，不写任何素材**；
2. 预检通过后按固定镜头表生成：Z-Image Turbo、Qwen-Image 2512 出关键帧，Qwen-Image-Edit 2511 换主体，SeedVR2 超清，Wan 2.2 图生视频，写入 `data/projects/demoClean1.json`；
3. 三步收口：

```bash
npm run demo:rebuild
DEMO_BOARD=data/projects/demoClean1.json npm run export:demo
PUBLIC_BASE=/ npm run build:demo
```

当前预检缺的文件（装到 ComfyUI 对应目录后即可重跑）：

- `models/diffusion_models/`：`qwen_image_edit_2511_int8_convrot`、`qwen_image_2512_fp8_e4m3fn`、`wan2.2_i2v_{high,low}_noise_14B_fp8_scaled`
- `models/text_encoders/`：`qwen_2.5_vl_7b_fp8_scaled`、`umt5_xxl_fp8_e4m3fn_scaled`
- `models/vae/`：`qwen_image_vae`、`wan_2.1_vae`
- `models/loras/`：`wan2.2_i2v_lightx2v_4steps_lora_v1_{high,low}_noise`

重跑后 `meta.json` 的 `licenses` 只会出现 Z-Image Turbo、Qwen-Image 2512、Qwen-Image-Edit 2511、SeedVR2、Wan 2.2，全部 Apache 2.0，不再出现 research-only 模型。

**不要删掉这段披露。** 评委看到的是"知道自己用了什么许可、也知道怎么换掉"，这比假装干净可信得多。
