# 造物故事：功能全在，作品为零

> 约 1,800 字。标了 `【按你实际…】` 的四处，请换成真实发生的事再发——这几处是整篇最有说服力的地方，编了反而会露。

---

比赛报名是 11 月 14 日填的。填之前我干了一件很蠢的事：打开自己的产品，想找一张作品截图当封面。

画布上没有作品。

只有 21 张测试生成的柯基犬，和 1 段用来验证视频链路的测试片段。它们歪歪扭扭地铺在无限画布上，每一张都连着它的提示词，每条线都对。

我盯着屏幕看了很久。`git log` 里是 53 次提交、两万六千多行代码；`npm test` 里 131 个测试全绿；我能给你讲清楚关键帧为什么必须是视频的第 0 秒，为什么台词会落在镜头后半段，为什么对白要统一到 -16 LUFS。功能全在，作品为零。

## 为什么做这个

我做这个的起点很具体：被积分和排队卡住过。

一个镜头不满意，改两行提示词，重新排队，等二十分钟，出来一张更差的。更难受的是素材和提示词都在别人的服务器上，我甚至没法确定明天打开它还在不在。后来我把生成搬回自己的机器：装上 ComfyUI，接一张显卡，世界清净了——但新的问题来了。

ComfyUI 给你的是**片段**。你想要一条能播的片，还得自己做剧本、分镜、人物一致性、台词、字幕、响度、剪辑。工具越强，中间这段手工活越重。

所以我想做的不是又一个生成器，而是**中间那一段**：从一句话到一条能播的片，每一步都留下痕迹，每一步都能单独返工。

## 第一次真跑

真正的打击在第一次完整跑一条片的时候。

【按你实际遇到的替换：第一次跑的是___题材的___秒短片，卡在第___步。】

我遇到的第一个问题是关键帧。我让关键帧画"她擦掉手机屏幕上的水"，画面很漂亮——动作已经擦完了。接下来视频里，她只能拿着手机干站着。我盯着那段 5 秒的视频看了三遍才反应过来：**视频是从第 0 秒开始演的，而第 0 秒的动作我已经在关键帧里用掉了。**

第二个问题是台词。分镜写的是 5 秒，台词说到第 4 秒半。我按分镜秒数裁，剪出来的成片里，最后半句没了。观众听到的是半句话，字幕也是半句。

第三个问题是站位。大全景里两个人一左一右，关键帧出来，人跑到门外去了；另一个镜头里，角色坐下的时候和椅子粘在了一起。

这些错误有一个共同点：**我的手册里全都写了，但我自己还是会犯。** 手册是写给人看的建议，人是会跳过的。

## 把规则变成会说不的工序

转折点是我意识到：这些规则不该只写在手册里，应该写成程序。

于是我把手册里的判断一条条变成工具和检查：

- 关键帧必须画"动作开始之前的那一瞬"，审片时按这条判；
- 每次审片把结论写回节点，分成本体不一致、构图错、穿模、动作没做出来、文字错——**不是一句"不好看"**；
- 每个结果最多重做两次，用完就停下来问人，不让自己无限抽卡；
- 剪辑前先听每一段，把"有明显声音但你要裁掉"的时间区间报出来；
- 助手用同样的参数连续做同一件事，第三次直接拒绝，逼它换做法。

这些东西看起来都不酷。它们不会生成更好看的画面，只会让你**交不出烂片**。

但正是它们把我从"抽卡"里捞了出来。以前一个镜头不满意，我的下意识是重出；现在我会先看审片结论：是人太小？那就先裁到这一镜的取景；是站位错？那就先在图上标位置。返工从"再赌一次"变成了"改一个具体的参数"。

## 现在它是什么

现在打开 Infinode，是一块空白画布，右下角一句话的输入框。

你写一句故事，它会先问你片长和画风，然后按题材排出节拍，写分镜表，等你点头才动手。接着出设定图、出关键帧、逐镜头出视频，最后剪辑成片——对白统一响度，中文字幕烧进画面，因为短剧观众经常静音刷。

每个结果都用一条线连回它的来源。你点开成片，能一路追到那句故事。哪个镜头不满意，只重做那一个，剩下的不动，成片重拼。

它不锁模型，也不锁工作流：任何 ComfyUI 的 API JSON 拖进来，就变成画布上的一键工具。

演示版（预置结果，不连 GPU）：https://37jvsot942shvcu7nwx.traesite.cn
完整版：`npm run dev`，跑在你自己的机器上。

## 最后一句

这 9 天我最大的收获不是多了几个功能，而是想明白一件事：

**画布不是产品，能交付的成片才是。**

一个功能齐全、测试全绿、但没有一条片的项目，和一个只有一条片、但每一步都能重来的项目，后者才叫作品。

我现在有一条片了。虽然它还短，还有两个镜头我不太满意——但我知道该改哪里，也知道改完不用重出全片。
