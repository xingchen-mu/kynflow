- **单集成本**：只归集可归属到同一集的实际支出；没有账单或实测记录时不估算。

### 4. 单集成本应采用的实际算法

当前各项输入均为**未统计**，所以本文件不报成本金额。后续补录时按实际用卡方式二选一，不用显卡 TDP 或公开单价倒推历史成本。

**自有卡：**

`单集电费 = 本集任务时段的整机实测耗电量（kWh） × 同期实际电价（元/kWh）`

- 用插座功率计或电表记录整机耗电；若只有功率采样，则按各任务时段的实测平均功率 × 实际时长累计。
- 只计本集生成、返工和剪辑对应时段；实际电价来自同期电费单。
- 显卡标称功耗、整机功耗猜测值均不得代替实测。

**租卡：**

`单集租卡成本 = 可归属到本集的租卡订单实付金额`

- 以平台订单、实例计费起止时间和支付记录为准；平台有最小计费单位时按真实账单计。
- 跨集共用实例且没有可分集核验的计费记录时，写“未统计”，不按感觉分摊。

**合计口径：**

`单集成本 = 自有卡电费或租卡实付 + 本集直接发生的第三方 API 实付（如有）`

当前不纳入口径的项目：硬件购置与折旧、人工、无法直接归属的存储和网络费用。若以后纳入，须另列口径与账单，不能和本次“未统计”的历史数据混算。
