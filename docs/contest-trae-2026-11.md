## 2. 这个项目过赛制的三处硬伤（不解决就是陪跑）

### 硬伤一：TRAE 记录的缺口（最致命）

项目 2026-10-31 – 11-08 的 53 次提交、26,000 行代码不是用 TRAE 做的；规则明确要 Session ID + 截图，且"不得用其他同类 AI 编程工具替代"。

**解法（唯一诚实的解法）**：
- 参赛期间（**11.14 起**）的**全部**开发与迭代在 TRAE CN 里做，并按天保存 Session ID + 截图；
- 让这段迭代**实质性可见于 diff**：出一个 `v0.3.0`，内容是"公网体验版 + 三条硬校验 + 交付打包"，不是改文案；
- 在提交材料里**如实划清边界**：此前有原型，参赛期间用 TRAE 完成了 A/B/C，Session 如下。这不是减分项——"把原型变成一个别人能打开的东西"本身就是最好的造物故事。
- **红线：绝不伪造 Session ID、绝不 PS 截图。** 规则第六条明令禁止造假，一次就出局。

### 硬伤二：评委"实际体验"不了（第二致命）

产品要自己的 ComfyUI + 几十 GB 模型；现有安装包只有 `arm64` 的 dmg / AppImage，**Windows 评委双击都打不开**。而规则要求"网页应用须部署至可公开访问的线上环境"。

**解法：做一个真正的 Demo 模式（也是本次参赛唯一必须新写的功能）。**
- 静态只读体验版：内置一条**已完成的短剧工程**（剧本笔记 → 设定图 → 关键帧 → 每镜头视频 → 成片），打开就能平移、缩放、点开成片播放、看到连线含义；
- 一个"体验生成"按钮：走真实 UI 与进度条，但结果来自**预置素材**（不是 GPU）；
- 页面顶部**明示**"演示模式：结果预置，不连接 GPU"——规则第六条要求信息真实；
- 部署到 Cloudflare Pages / Vercel / GitHub Pages（免费、无冷启动、零运维），得到公网 URL。
- 同时给：`docker compose up` 或 `npm run dev` 一条命令，供有卡的评委本地跑真链路。

### 硬伤三：模型许可（很多人会栽在这，你反而是加分项）

`shared/licenses.ts` 写得很清楚：

| 模型 | 许可 | 对你公开演示意味着 |
|---|---|---|
| **Qwen-Image 2.1**（默认内置文生图） | Qwen Research License | **不可商用，仅研究评估** → 公开片别用它当主链路 |
| **MiniMax H3**（默认内置视频） | H3 Community License | 有条件商用，**不覆盖美/欧/英/韩**，且界面须标注 → 公网页面在这些地区有风险 |
| Qwen-Image 2512 / Edit 2511 / Z-Image Turbo / Wan 2.2 / SeedVR2 / FLUX.2 klein 4B | Apache 2.0 | **全干净，公开片优先用这套** |

**建议**：演示片的公开链路走 **Z-Image Turbo 或 Qwen-Image 2512（关键帧）+ Wan 2.2（镜头）+ 后期 TTS 配音 + 火焰/字幕收口**，交付材料附一页《模型与素材许可说明》。这一页在评委眼里是"专业度"，在别的参赛者那里是"没想过"。

### A. 产品说明（300 字，报名表用）

> Kynflow 是一个跑在你自己电脑上的 AI 短剧制片台。写一句话给出故事，它按导演手册把片子一步步做出来：剧本 → 分镜表 → 人物与场景设定图 → 每个镜头的关键帧 → 每个镜头一段视频 → 自动剪辑成片（对白响度统一、字幕烧录）。所有生成都交给你自己的 ComfyUI，不经过任何云平台，没有积分、没有排队、没有审查。

### C. 造物故事（1,500 字，最可能拿奖的那篇）

**不要写成"我做了个牛逼产品"，要写成"我以为我做完了，结果我连一条片子都没跑出来"。**

3. 转折：参赛后第一次真的跑一条 60 秒片，卡在第几步（这一段越具体越好：关键帧一画就把动作画完了、台词被剪辑切掉半句、某个镜头角色变脸…）。
4. 解决：把手册里的规则变成程序校验——"不是写给人看的建议，是交不了片的门禁"。
5. 收尾：一个能点开的链接 + 一条能看的片。以及一句真话：**"画布不是产品，能交付的成片才是。"**

## 11. Demo 模式（2026-11-15 已完成）

静态体验版已实现，规格见 `docs/demo-mode-spec.md`：

```bash
npm run export:demo   # 从 data/ 里的真实画布导出 demo/（board.json + meta.json + webp）
npm run build:demo    # 产出 dist-demo/，默认按 /kynflow/ 子路径构建
PUBLIC_BASE=/ npm run build:demo   # 部署在域名根目录时用这个
```

- 只在 `src/lib/api.ts` 换成 `src/lib/demo.ts` 的适配层，正常模式行为不变；
- 顶部常驻「演示模式 · 结果为预置素材，不连接 GPU」，首屏对准成片，可点「看成片」「试一下」；
- `npm run typecheck` / `npm test`（148 项）/ `npm run build` / `npm run smoke` 均通过；`dist-demo` 约 2.1 MB。

### 发布到 GitHub Pages

1. 仓库需为公开（私有仓库的 Pages 需要 GitHub Pro）；
2. `npm run build:demo`，把 `dist-demo/` 推到 `gh-pages` 分支（或 `docs/` 目录）；
