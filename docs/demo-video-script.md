# 3 分钟演示视频脚本（可照着直接录）

> 对应赛道：**02 内容创作**。
> 评分轴：**A 从构思到成品 / B 内容质量 / C 创作体验 / D 表达方式 / 反命题：不只是一次 AI 输出**（见 `docs/track-content-optimization.md` §1）。
> 硬性要求：**0:00–0:08 必须是成片本身**——不要画布、不要 logo、不要片头、不要解说，只留成片原声与字幕。
> 总长 180 秒，误差控制在 ±2 秒内。旁白按 4.2 字/秒写，念完刚好卡点。

---

## 0. 录前准备（不完成不要开录）

### 0.1 工程必须长这样（完整版，不是 Demo 版）

一个画布，从左到右七个区域，每个区域之间留出连线的空隙：

1. **一句话**：一张文本便签，只有一句话（例：`雨夜，她把最后一条语音听完，删掉了联系人。`）。
2. **剧本**：一张文本便签，八节拍，标出开头三秒。
3. **分镜表**：一张文本便签，表格列 = 镜号 / 景别 / 起始画面 / 台词 / 时长。
4. **设定图**：人物 1–2 张 + 场景 1 张（无人的大全景）。
5. **关键帧**：每个镜头一张首帧图，命名统一（`KF-01`、`KF-02`…）。
6. **镜头视频**：每个镜头一段，命名统一（`S01`、`S02`…），第一段输入连到对应关键帧。
7. **成片**：`assemble_video` 拼过一次的最终视频，字幕已烧在画面下方。

另外必须准备第 3 镜的两套素材：

| 素材 | 内容 | 用途 |
|---|---|---|
| `KF-03 v1` | 关键帧里动作**已经做完**（手停在擦完的位置） | 0:38–0:45 说明「为什么 v1 不行」 |
| `S03 v1` | 用 v1 生成的片段（人物基本站着不动） | 同上，播放给人看 |
| `KF-03 v2` | 关键帧画的是动作**开始之前的一瞬** | 0:45–0:58 的对照 |
| `S03 v2` | 用 v2 重新生成的片段（动作真的发生） | 同上 |

### 0.2 把「系统拒绝你」做成可复现的状态

这是全片最值钱的 1 秒，不能靠临场碰运气。录制前把工程调成下面这个状态：

- 画布上第 3 镜的**当前关键帧已经是 v2**；
- 但第 3 镜的**视频节点仍然是 v1 生成的那条**（没有重做）；
- 此时对助手说「按分镜顺序重剪一版」，`assemble_video` 会比对每段视频第 0 秒与它的首帧，必然报错：
  `关键帧检查没通过：…第 0 秒和首帧对不上…`

录完 0:58–1:18 这一段后，再按脚本现场生成 v2 的片段并重剪，工程回到正常状态。

### 0.3 录前量好这五个数字（S9 要念，禁止编造）

写在一张便签上，镜头拍到也不怕：

- 总墙钟时间（从写下第一句话到成片落地）：`__ 小时 __ 分`
- GPU 实跑：`__ 分钟`
- 重做镜头数 / 次数：`__ 个 / __ 次`
- 单集成本：`__ 元`（口径必须能说清：租卡 `__ 元/小时 × __ 小时`，或本地电费折算）
- 失败次数与类型：`__ 次`（掉线 / 显存不足 / 模型未安装 / 被取消）

### 0.4 录制设置

- 窗口 1600×1000 或 1920×1080；浏览器缩放 100%；隐藏书签栏；关掉系统通知。
- 录屏 60fps；打开鼠标点击高亮；麦克风单独一轨，方便后期压成片原声。
- 所有要输入的文字提前放备忘录，用**粘贴**，不要现场手打（避免录到错字和输入法候选框）。
- 生成等待段落用 **8× 快放**，右下角标真实耗时（例：`等待 6 分 12 秒，8× 快放`）。
- 前 90 秒不要出现 Demo 版的「演示模式」横条；Demo 只在 1:50–2:20 出现。

### 0.5 成片开头自检

先完整看一遍成片。**0–8 秒内必须有第一句台词和字幕**；如果开场是空镜：

- 把开场字幕卡压到 3 秒内，或
- 重剪时把第一句台词提到 4 秒左右。

不要用「从中间截 8 秒」代替——评委要看到的是这条片子的开头。

## 2. 逐段执行卡

### S1｜0:00.0–0:08.0｜成片开场

- **画面**：成片画面满屏。有台词、有字幕、有声音。无任何 UI、无鼠标、无字幕条。
- **旁白原话**：无。只留成片原声；成片音量比后面旁白高 3–4 dB。
- **录屏动线**：
  1. 双击成片节点 → 灯箱自动播放。
  2. 如果已经播过，按 `Esc` 关掉灯箱，重新双击，确保从第 0.0 秒开始。
  3. 录满 8 秒即停；后期在 8.0 秒处硬切，不要淡入淡出。
- **评分轴**：A 从构思到成品 / B 内容质量。
- **录制要点**：这一段的唯一任务是让评委抬头。不要叠任何文字；不要放产品名。

### S2｜0:08.0–0:16.0｜定位

- **画面**：硬切到画布全貌（全链路缩放到一屏），成片节点在右下角，连线清晰可见。
- **旁白原话**（0:08 起）：
  > 这不是一次生成。这是一条片，从一句话到成片，每一步都留在画布上。
- **录屏动线**：
  1. 切到完整版窗口（右上角显示 ComfyUI 已连接，不是「本地服务未连接」）。
  2. 点左侧工具栏「显示全部（⇧1）」，或直接按 `⇧1`。
  3. 鼠标从左上慢慢移到右下成片，停住，不要点任何东西。
- **评分轴**：反命题（不只是一次 AI 输出）。
- **录制要点**：不要出现 Demo 横条；这里要让评委相信这是一条真做完的片子。

### S3｜0:16.0–0:38.0｜一句话 → 剧本 → 分镜

- **画面**：三张便签依次放大；每张右上角用后期角标标真实耗时（如「剧本 2 分 40 秒」「分镜 1 分 12 秒」）。
- **旁白原话**（0:16 起）：
  > 起点只有一句话。助手先按短剧手册排八个节拍，写成剧本；再拆成分镜表：每个镜头的景别、台词、时长。这里一共【N】个镜头，成片【X】秒。
  >
  > （念完约 0:33，剩下 5 秒只留滚屏环境声。）
- **录屏动线**：
  1. 双击「一句话」便签 → 停留 2 秒，让镜头看清整句。
  2. `Esc` → 双击「剧本」便签 → 向下滚两屏 → 停住。
  3. `Esc` → 双击「分镜表」便签 → 滚到第 3 行 → 鼠标停在第 3 镜那一行。
  4. 按 `⇧1` 回到全貌，准备下一段。
- **评分轴**：A（从构思到成品）。
- **录制要点**：便签里的文字要能在 1080p 下读清；字号提前调大，别让评委暂停才看清。

### S4｜0:38.0–0:58.0｜设定图 → 关键帧 v1 / v2

- **画面**：设定图 → v1 关键帧 → v1 片段（人物干站）→ v2 关键帧 → v2 片段（动作发生）。v1 和 v2 后期并排一小段，标 `v1` / `v2`。
- **旁白原话**（0:38 起）：
  > 设定图管人物长什么样、光从哪来。第一版关键帧我画错了：动作已经做完了，视频里他没东西可演，只能站着。改成动作开始前的一瞬，这一段才动。
  >
  > （念完约 0:55。）
- **录屏动线**：
  1. 点设定图 → 停留 1.5 秒。
  2. 按 `空格` 拖动画布到第 3 镜。
  3. 鼠标悬停 `KF-03 v1` → 双击 `S03 v1` 全屏播放 3 秒（人物几乎不动）→ `Esc`。
  4. 鼠标悬停 `KF-03 v2` → 双击 `S03 v2` 全屏播放 3 秒（动作发生）→ `Esc`。
  5. 后期把两段播放并排：左 `v1`、右 `v2`，各留 3 秒。
- **评分轴**：B（内容质量：创作者有没有判断力）。
- **录制要点**：v1 片段一定要真的「没东西可演」，这是判断力的证据；不要用两段都好看的素材。

### S5｜0:58.0–1:18.0｜只重做第 3 镜（全片最值钱的 20 秒）

- **画面**：助手面板报红 → 撤回只改这一段 → 新片段落地 → 重剪完成，新成片出现。
- **旁白原话**（0:58 起）：
  > 我改了第 3 镜的关键帧，忘了重做这段视频。剪辑时它拦住了我：这一段的第 0 秒，和首帧对不上。只重做这一段，再剪一次，其他镜头一个没动。
  >
  > （念完约 1:16。）
- **录屏动线**：
  1. 0:58 点右上「助手」→ 面板展开。
  2. 0:59 在「想让助手做什么？打 / 用命令」输入框粘贴：`按分镜顺序重剪一版，第 3 镜用新的关键帧` → `Enter`。
  3. 1:02 面板出现红色错误行，含「关键帧检查没通过」「第 0 秒和首帧对不上」。**鼠标停在错误行 1.5 秒**——这是全片最值钱的一秒，不要剪掉。
  4. 1:05 选中 `KF-03 v2` → 工具栏点「生视频」。
  5. 1:06 在底部输入框粘贴：`她抬手去擦手机屏幕，手停在一半，窗外雨声` → `Enter`。
  6. 1:07 右上「任务」变成「1 个任务进行中」→ 录到进度走完。**这一段 8× 快放**，角标写真实耗时。
  7. 1:13 新片段落在画布 → 回到助手输入框粘贴：`用新生成的这一段重剪` → `Enter`。
  8. 1:15 等「剪辑成片」完成 → 画布右侧出现新成片节点 → 鼠标框选新旧成片，停 1 秒。
- **评分轴**：C（创作体验：只重做坏的那一个）+ 反命题（系统会说不）。
- **录制要点**：
  - 报错行必须完整入画，不要被面板裁掉；提前把助手面板拉宽。
  - 如果 `assemble_video` 没有报错，说明第 3 镜的视频已经和 v2 匹配了——回到 §0.2 重置状态重录，不要用旁白硬说「它拦住了我」。

### S6｜1:18.0–1:32.0｜血统：从成片追回那句话

- **画面**：节点信息弹窗一层层往上点：成片 → 镜头 03 → 关键帧 03 → 设定图 → 分镜表 → 一句话。
- **旁白原话**（1:18 起）：
  > 每个结果都连回它的输入：从成片，到这一段，到它的关键帧，再到设定图和分镜表。追到最上面，就是我写的那句话。
- **录屏动线**：
  1. 单击成片 → 悬浮工具栏点「查看节点信息」（Info 图标）。
  2. 弹窗「输入链路」里点「镜头 03」chip → 自动跳到该片段并关闭弹窗。
  3. 再点「查看节点信息」→ 点「关键帧 03」。
  4. 再点「查看节点信息」→ 点设定图（例「女主 · 设定」）。
  5. 再点「查看节点信息」→ 点「分镜表」。
  6. 最后点「分镜表」的输入 →「一句话」→ `Esc` 关闭。
- **评分轴**：D（表达方式：别人没有的追溯方式）。
- **录制要点**：每一步都要让 chip 的文字入画；节点命名提前改成人能读的（`镜头 03`，不要 `aB3xK9`）。

### S7｜1:32.0–1:50.0｜成片 + 交付物

- **画面**：成片全屏播放 12 秒（挑台词最密的一段），字幕在画面下方；右侧「详情」露出时长、尺寸、模型；最后 3 秒回到画布，鼠标指向成片节点和「下载原图」。
- **旁白原话**（1:32 起）：
  > 这条片【X】秒，【N】个镜头。对白统一到 -16 LUFS，中文字幕直接烧进画面——短剧观众常常静音刷。交付的是一条 mp4，和一整张还能继续改的画布。
- **录屏动线**：
  1. 双击成片 → 灯箱自动播放 → 录 12 秒。
  2. 鼠标移到右侧「详情」，在「时长」「尺寸」两行上各停 1 秒。
  3. 鼠标移到「下载原图」按钮上（**不要点**，避免弹出下载框）。
  4. `Esc` → 按 `⇧1` 回到全貌，鼠标沿成片的输入连线扫一遍。
- **评分轴**：A（成品可交付）/ B（内容质量）。
- **录制要点**：播放的这 12 秒要选有台词、有字幕、音乐不吵的一段；不要选空镜。

### S8｜1:50.0–2:20.0｜评委自己怎么看

- **画面**：浏览器全屏打开公网 Demo → 首屏（成片节点 + 顶部横条）→ 点「看成片」→ 关闭 → 点「看全链路」→ 点「试一下」→ 假进度走完；随后切终端敲一条命令；再切回页面，右上角 ComfyUI 已连接。
- **旁白原话**（1:50 起）：
  > 评委不用装东西：打开链接就是一条做完的片子，顶部写着「预置、不连 GPU」。「看成片」能播，「看全链路」能看到每一步，「试一下」走一遍真实的任务流程。有卡的机器，一条命令起完整版。公开素材的模型许可，页面上直接标。
  >
  > （念完约 2:15。）
- **录屏动线**：
  1. 切浏览器，地址栏完整入画 2 秒（公网 URL）。
  2. 点顶部「看成片」→ 播 3 秒 → 关闭。
  3. 点顶部「看全链路」→ 停留 2 秒（画面缩放到整张画布）。
  4. 点顶部「试一下」→ 等假进度走完 → 落下预置图 → 出现 toast「演示模式：结果是预置素材，不会真的生成」。
  5. 切终端，输入 `npm install && npm run dev:noTunnel`（已装过依赖就只演示后者）→ 回车。
  6. 切回页面，右上角状态显示 ComfyUI 已连接。
- **评分轴**：加分（可被体验 + 权属清晰 + 信息真实）。
- **许可口径（二选一，必须和 Demo 实际素材一致）**：
  - 若 11/17–18 已用干净模型重跑并重导 Demo：
    > 公开链路用的是 Apache 2.0 的 Z-Image 和 Wan 2.2，能不能商用，界面上直接标。
  - 若还没重导：
    > 预置素材里用了 Qwen-Image 2.1 和 MiniMax H3，许可限制写在页面和提交材料里。
- **录制要点**：Demo 的「演示模式」横条必须入画；这是规则第六条要求的诚实标注，不是缺点。

> 0:16 起点只有一句话。助手先按短剧手册排八个节拍，写成剧本；再拆成分镜表：每个镜头的景别、台词、时长。这里一共【N】个镜头，成片【X】秒。

> 0:38 设定图管人物长什么样、光从哪来。第一版关键帧我画错了：动作已经做完了，视频里他没东西可演，只能站着。改成动作开始前的一瞬，这一段才动。

> 0:58 我改了第 3 镜的关键帧，忘了重做这段视频。剪辑时它拦住了我：这一段的第 0 秒，和首帧对不上。只重做这一段，再剪一次，其他镜头一个没动。
>
> 1:18 每个结果都连回它的输入：从成片，到这一段，到它的关键帧，再到设定图和分镜表。追到最上面，就是我写的那句话。
>
> 1:32 这条片【X】秒，【N】个镜头。对白统一到 -16 LUFS，中文字幕直接烧进画面——短剧观众常常静音刷。交付的是一条 mp4，和一整张还能继续改的画布。

> 1:50 评委不用装东西：打开链接就是一条做完的片子，顶部写着「预置、不连 GPU」。「看成片」能播，「看全链路」能看到每一步，「试一下」走一遍真实的任务流程。有卡的机器，一条命令起完整版。公开素材的模型许可，页面上直接标。

## 4. 后期规格与检查

- 成片 1920×1080 / 30 或 60fps / H.264；平台上限内，文件建议 < 200 MB。
- 旁白与成片原声分轨：成片原声 −14 LUFS 左右，旁白 −16 LUFS；S1 的成片原声比旁白高 3–4 dB。
- 只在三种地方加字：S3 的三张便签角标（真实耗时）、S5 的快放角标、S9 的统计卡。其余画面不加花字。
- 全片不出现「一键生成」「秒出片」「零门槛」这类词；不出现未验证的用户量/收入。
- 交付前逐项对照：
  - [ ] 0:00–0:08 只有成片，无 UI、无 logo、无旁白
  - [ ] 0:08 硬切，不是淡入
  - [ ] S5 的报错行完整、清楚、停留 ≥1.5 秒
  - [ ] S8 的「演示模式」横条入画
  - [ ] 所有【】占位都替换成实测值
  - [ ] 结束卡的 Demo URL / GitHub 地址当天可打开

## 5. 风险与替代方案

| 风险 | 表现 | 当场怎么办 |
|---|---|---|
| 门禁没触发 | 重剪时没有报「关键帧检查没通过」 | 按 §0.2 重置：保留 v1 片段 + v2 关键帧，再重剪一次；不要用旁白假装它拦了 |
| GPU 排队/掉线 | 镜头生成超过 10 分钟 | 这一段本来就 8× 快放；角标写真实耗时，失败重试也保留 2 秒 |
| Demo 还是旧素材 | 画布上只有一条 3 秒片，不是短剧 | S8 只演示按钮与「预置」标注，不解说画布内容；11/17–18 重导后再补拍 S8 |
| 成片开头没台词 | 0–8 秒是空镜 | 按 §0.5 重剪开场，把第一句台词提到 4 秒左右，再录 |
