## 3. 唯一能守住的差异：他们停在"素材"，你收到"成片"

**这是硬证据，不是说法。** Toonflow README 全文检索：

```
剪辑: 0    成片: 2（都在案例那一行）    合成: 0    字幕: 0
响度: 0    配音: 0                     时间线: 0  导出: 0
```

它的制作流程第 4 步原文是：**"预览、整理与下载：在无限画布中预览和组织图片、视频片段，**下载素材后按创作需求继续处理**。"**

也就是说：Toonflow 做到"每个镜头一段视频"，然后把片子交给剪映。你的 `assemble_video` + `inspect_clips` + 对白 `-16 LUFS` + 中文字幕烧录 + 硬切，是它明确不做的那一步。

**而 TRAE 内容创作赛道的原文定义是**：「帮助创作者完成**从构思到成品**的创作过程……我们期待作品在内容质量、创作体验和表达方式上带来的改善，而**不只是一次 AI 输出**。」

**赛道定义就是你的差异点。** 这是这份链接带来的唯一、也是最重要的战略修正。

## 4. 如果评委问"这不就是 Toonflow 吗"

准备一个 30 秒答案，**不贬低对方、不辩解，只讲能力边界**：

> "Toonflow 是一张很好的素材画布，做到每个镜头一段视频就结束了，剪片还在剪映里。我们做的是它之后那一步：把镜头拼成一条能播的片——对白统一到同一个响度、中文字幕烧进去、每段的台词位置自动找。我们统计过，AI 短剧的成本里生成只占 40%，调改占 45%，那 45% 全发生在'从素材到成片'这一段。另外，我们部分工艺手册是整理自 Toonflow 的（MIT，已在 THIRD_PARTY_NOTICES 注明）。"

三句话覆盖：差异在哪 → 为什么值钱 → 我们诚实。

**材料里不要主动点名对手**（显得心虚），但**必须准备这个答案**，因为只要有人用过 Toonflow 就会问。反过来，被问到时能答得这么清楚，是加分。

## 5. 九天里能抄的 5 件（成本低、见效快）

1. **一个带数字的案例页**。Toonflow 全站最有说服力的一行是"2 小时 / 2 分钟 / ¥130"。你需要等价的一行：`X 小时 / 90 秒成片 / ¥Y（电费 + API）/ N 个镜头重做 M 次`。**没有数字的案例等于没有案例。**
2. **每周一个版本号 + Release 资产**。参赛前发 `v0.3.0`，Release 页放 demo 包与截图。发版本身是"产品完整"的证据。
3. **Gitee 镜像**。国内可达性 + 中文社区入口，半小时的事。
4. **Docker 一行启动**。`docker compose up -d` → `127.0.0.1:8787`。这是给有卡的评委唯一现实的上手路径，也补掉"只有 arm64 安装包"的死穴。
5. **FAQ / SEO 段**。README 末尾加「能不能接自己的模型」「免费吗」「要显卡吗」三问三答——他们那套问答明显是从搜索词反推的，直接照抄结构。
