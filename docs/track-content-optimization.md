# 内容创作赛道：宗旨拆解与优化清单

## 1. 宗旨原文（海报逐字）

> **内容创作 02**
> 帮助创作者完成**从构思到成品**的创作过程。无论是写作、视频还是设计，我们期待作品在**内容质量、创作体验和表达方式**上带来的改善，而**不只是一次 AI 输出**。
> 例如：内容写作、视频制作、设计绘画、**短剧生产**、创作素材整理。

这段话里藏着 4 条评分轴 + 1 条反命题：

| # | 评分轴 | 评委真正在问的问题 |
|---|---|---|
| A | **从构思到成品** | 你交的是"一段素材"，还是"一个能播的东西"？ |
| B | **内容质量** | 做出来的东西本身好看吗？创作者有没有判断力，还是只会抽卡？ |
| C | **创作体验** | 改一次要多久？能不能只重做坏的那一个？出事能不能退回去？ |
| D | **表达方式** | 除了"生成"，你有没有给出别人没有的表达手段？ |
| — | **反命题：不只是一次 AI 输出** | 这是多轮的、可审的、能被否掉重来的，还是"输入一句话，出个东西"？ |

**注意 A 和反命题的关系**：赛道明确排除了"只做一次 AI 输出"。所以**生成能力在这个赛道里不减分，但也不加分**——加分的是生成之前和之后的那部分。

---

## 2. 你现在的处境：四条轴，代码里都埋着，但一条都没被看见

| 轴 | 代码里的现状 | 被看见了吗 |
|---|---|---|
| A 从构思到成品 | `short_drama` 七步手册 + `assemble_video` + 响度 + 字幕 | ❌ **从未端到端跑通过一次** |
| B 内容质量 | 19,602 字工艺手册（8 节拍、情感锚点、开头三秒、关键帧必须是第 0 秒） | ❌ 一段成片都没有 |
| C 创作体验 | 27 工具 + 单镜头重做 + GPU 时间审批 + rewind + 快照 | ❌ 演示里从没演过"返工" |
| D 表达方式 | 连线血统（每个结果连回输入） | ❌ 只被当成 UI 装饰 |
| 反命题 | 三条可做的硬校验（关键帧第 0 秒 / 稳定性预检 / 导出前检查） | ❌ 还没写 |

**结论：不是产品不行，是这四条轴一条都没变成"可看的 15 秒"。** 优化不是加功能，是**给每条轴造一个 15 秒的可视证据**，然后串成 90 秒。

---

## 3. 优化动作：一条轴对一个证据

| 轴 | 要造的 15 秒证据 | 具体做什么（9 天内） |
|---|---|---|
| **A 从构思到成品** | 一句话 → 成片的**单线时间轴**，每一步标耗时 | 用真实一条片跑通；屏幕录制保留每一步；结尾给"总耗时 / 总成本" |
| **B 内容质量** | **同一镜头的 v1 vs v2 对比**，说清为什么 v1 不行 | 故意做一个错的关键帧（动作在图里已经做完）→ 视频里没东西可演 → 按手册改成"动作开始前的一瞬"；两版并排 |
| **C 创作体验** | **只重做第 3 个镜头**的动线 + 返工成本数字 | demo 里加"重做这一个"按钮动线；视频里演示一次；报"重做 1 镜头 = X 分钟 / ¥Y，不用重出全片" |
| **D 表达方式** | **血统图**：从成片向下追到那句话 | demo 首屏一个"看它是怎么来的"入口，点开是一条链路而不是一堆素材 |
| **反命题** | **系统拒绝你**的那一秒 | 三条硬校验里至少做 1 条并让它当场拦住：弹"这个镜头会被判断为动作已完成，建议改为…" |

**其中"系统拒绝你"这一秒是全片最值钱的镜头。** 它一句话证明了：这不是一次 AI 输出，这里有个会说不的工序。

---

## 4. 优先级（按 9 天 ROI 排，别按喜好排）

### P0 —— 不做就没有作品（11/15–11/19）
1. **真实跑通一条 60–90 秒成片**（含字幕与对白响度）。这是 A 轴的全部。
2. **公网 demo**（预置素材、可点开、可操作、明确标注"演示模式"）。这是"可被体验"的门票。
3. **90 秒演示视频**，按 A→B→C→D→反命题 的顺序剪。

### P1 —— 决定能不能进前 20（11/16–11/21，可与 P0 并行）
4. **一条硬校验**（优先"关键帧必须是视频第 0 秒"）：当场拦住，并给出修改建议。
5. **单镜头返工动线**：点一个镜头 → 只重做它 → 其余不动 → 成片自动重拼。
6. **血统链路**：成片 → 镜头 → 关键帧 → 设定图 → 分镜 → 一句话，可点可追。

### P2 —— 锦上添花（11/21–11/22）
7. README 60 行 + 证据徽章 + 成片 GIF。
8. 案例数字一页：`X 小时 / 90 秒成片 / ¥Y / N 个镜头重做 M 次`。
9. Gitee 镜像 + `docker compose up` 一行启动。

### 直接砍（9 天装不下，且不加分）
21 种语言、插件市场、Android、签名公证、桌面打包优先、MCP 推广、画布搜索/滤镜长尾、25 个模板（留 3 个）。

## 5. 评委那 3 分钟，你希望他看到什么（时间轴脚本）

| 时间 | 画面 | 对应评分轴 |
|---|---|---|
| 0:00–0:08 | **成片直接播前 8 秒**（有台词、有字幕、有声音） | A / B |
| 0:08–0:15 | 一句定位：*"这不是一次生成，这是一条片的制作过程"* | 反命题 |
| 0:15–0:35 | 一句话 → 剧本 → 分镜表（20 秒走完三步，标耗时） | A |
| 0:35–0:50 | 设定图 → 关键帧；**播放 v1 错误版被拦下 → v2** | B + 反命题 |
| 0:50–1:10 | 只重做第 3 个镜头 → 成片自动重拼（返工成本数字） | C |
| 1:10–1:25 | **血统图**：成片往下追到那句话 | D |
| 1:25–1:40 | 成片完整播一遍 + 交付物清单（mp4 / srt / 响度报告） | A / B |
| 1:40–3:00 | 实机上手指南（docker 一行）+ 许可说明 + 成本账 | 加分 |

**前 8 秒必须是成片本身**。评委一天看几十个"画布演示"，只有成片能让人抬头。

## 6. 一个反直觉但很重要的建议：用导演语言写材料

内容创作赛道的评委，对"技术语言"免疫，对"创作语言"敏感。

| 别这样写 | 这样写 |
|---|---|
| "支持多模型工作流编排" | "每个镜头单独出、单独重做，改一版不用重出全片" |
| "Agent 调用 27 个工具" | "它先问你片长，再按题材排 8 个节拍，写完分镜等你点头才动手" |
| "集成 ffmpeg 后处理" | "对白自动统一到同一个音量，中文字幕烧进画面——因为短剧观众常常静音刷" |
| "关键帧一致性校验" | "关键帧必须画动作发生之前的那一瞬，否则视频里的人物只能干站着" |

你仓库里那 19,602 字手册**就是这套语言的词典**。别的参赛者写不出这种句子，这是你唯一不用说谎就能拉开的差距。

## 7. 一句话
