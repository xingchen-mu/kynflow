# Infinode 处境体检与出路（2026-11-14）

> 依据：本仓库代码与 `data/` 运行记录的实测，加 2025Q4–2026Q4 的公开市场调研。
> 硬数据 = 本机实测；调研数据 = 外部来源，均标了时间，随平台调价/改版会过时。
>
> 更新（2026-11-22）：本文写于 2026-11-14，当时仓库为私有、对外 404、站点在 `xingchen-mu.github.io/infinode/`。此后仓库已公开并更名为 `xingchen-mu/kynflow`，站点迁移到 `xingchen-mu.github.io/kynflow/`；文中关于「私有 / 404 / 旧站点」的事实描述已不适用，其余分析保留当时的判断。

---

## 0. 一句话结论

**这个项目的瓶颈不是能力，是证据。** 工程侧已经超配（9 天 26,000 行、131 个测试全过、27 个 agent 工具），商业侧是零（仓库是私有、对外 404、零用户、零真实产物、旗舰功能一次都没跑通）。
加功能的边际收益已经接近 0；**做出一条能给人看的片子，价值高于再写三万行代码。**

出路只有一条主线：**别再卖"画布"，去卖"制片后台"**——把无限画布降级成界面，把三个真资产（工作流适配层、工艺知识库、成本可审计的 agent 管线）做成一条能交付成片的流水线，只服务一类人：靠 AI 短剧/商业素材吃饭的承制方。

## 1. 现状体检：一台运转良好、但没接上任何东西的机器

### 1.1 工程侧（强，且是真的强）

| 指标 | 实测 |
|---|---|
| 提交 | 53 个，2026-10-31 → 2026-11-08（9 天） |
| 代码量 | `src` 11,244 + `server` 10,180 + `shared` 1,871 + `test` 3,041 ≈ **26,300 行**（另有 8,924 行模板 JSON） |
| 类型检查 | `tsc --noEmit` 通过 |
| 测试 | **131 个全过**（导入、HTTP、并发落盘、媒体分片都有覆盖） |
| Agent 工具 | 27 个（含 plan 审批、预算确认、rewind、记忆、MCP 服务） |
| 模板 | 25 个官方工作流预设 |
| 工艺知识库 | `guides.ts` + `craft.ts` 合计 **19,602 个汉字**的导演/分镜/提示词/剪辑手册 |
| 最近活动 | **2026-11-08 之后无提交，`data/` 最后写入是 11-05**，已空转 6–9 天 |

这是一个能跑、有测试、结构清晰（`src` / `server` / `shared` 分层，后端不反向依赖前端）的代码库。工程质量不是问题。

### 1.2 商业侧（零）

| 指标 | 实测 |
|---|---|
| 公开可见性 | 远端仓库是**私有**（`git ls-remote` 可读到 main 与 v0.1.0/v0.2.0），匿名访问 `github.com/xingchen-mu/infinode` → **404**。也就是说：仓库在，但外面看不到 |
| 提交者身份 | `Infinode <infinode@invalid>`——没有真人身份、没有个人品牌、没有 building in public |
| 画布 | `data/projects/` 7 个，全部 0–2 个节点，名字是「界面测试」「真实环境验证·自动恢复成功」「演示画布」 |
| 生成记录 | 21 个任务（17 成功 / 2 失败 / 2 取消），prompt 是「戴着飞行员护目镜的柯基犬」这类冒烟测试 |
| 素材 | 39 个，全是测试图（`zimage_00002_.png`、`qwen_00002_.png`） |
| 视频 | **1 个 mp4，就一个** |

### 1.3 由此得到的两个判决

**判决一：旗舰叙事从未被验证过一次。**
README 和 `short_drama` 手册承诺的是「一句话 → 剧本 → 分镜 → 设定图 → 关键帧 → 每镜头视频 → 剪辑成片、对白响度归一、烧字幕」。这条链路的代码（3,000+ 行手册 + `assemble_video` + `inspect_clips` + `silencedetect` + `-16 LUFS`）**从来没有端到端跑通过一遍**。作者自己没做过一条片子。

**判决二：这个项目对外等于不存在。**
仓库私有（对外 404）、无 star 无 issue 无 release 页面、无身份。产品页 `xingchen-mu.github.io/infinode/` 还活着（200），但没人会到那里去。**现在的风险不是被竞品打败，是它从来没被任何人看见过。**

## 2. 三个结构性错配（为什么"再多做一点"救不了它）

### 错配一：能力与证据的错配
26,000 行代码 vs 1 个测试 mp4。在这种比例下，任何新功能都是**在给一个没人验证过的假设加杠杆**。工程越漂亮，沉没成本越高，越不敢收窄。

### 错配二：产品形态与坟场高度重合
"本地优先 + 无限画布 + AI"这个形态，2026 年已经有一排尸体：

| 项目 | 结局 | 死因 |
|---|---|---|
| **Kosmik**（本地优先无限画布 + AI 情绪板，做了 8 年，Creandum 投过） | 2026-05-31 日落 | 形态对、需求假 |
| **Infinite-Canvas**（3.2k★ / 629 fork，国产 ComfyUI 画布） | 2026-08-28 停更 | README 自述"很多 API 网址关停"，继任者转向账号体系+协同+公网图床 |
| **Playground Board** | 2026-01-06 关画布、退款 | 官方原话：转做平面设计；画布不构成护城河 |
| **Cove** | 2026-04-01 关服删数据 | 团队被微软吸收 |
| **Flowise**（55,000★） | 2026-08-13 归档 EOL | 停服说明点名：开发者改用 coding agent，刚性低代码工作流一遇复杂度就到顶 |
| **InvokeAI 托管版**（开源 28.3k★） | 2025-10 团队进 Adobe，托管关停 | 单机专业工作台做不成订阅生意 |
| **Fooocus**（54k★） | 2024-08 后 LTS | 靠爱发电，不追新模型 |

**关键事实：这个生态位里从来没有一个"独立画布产品"上过 10k star 并持续增长。最高的 3.2k 是已停更的 Infinite-Canvas。** 而有模型或有流量的云画布活得很好：Krea 4,000 万创作者、Magnific ARR 2.3 亿美元 / 100 万付费、Flora 拿了 4,200 万美元 A 轮（客户 Nike / Netflix / Pentagram）、Lovart 4 个月 ARR 3,000 万美元。

画布本身不是产品，**它只是模型能力不足时的脚手架**。把画布当卖点，就是在重走 Kosmik 的八年。

### 错配三：卖点与付费意愿的错配
现在有六个功能，等于六个产品，每个都对着一个更强的房东：

| 功能 | 房东 | 处境 |
|---|---|---|
| 无限画布 | Krea / Magnific / Flora（免费额度）+ ComfyArt（530★，同生态同形态，还在更新） | 正面打不过 |
| 画布 agent | 官方 **Comfy Agent**（2026-10-01，绑定 Cloud 积分）+ Krea Node Agent | 官方在做，方向一致 |
| MCP 服务 | 每个 CLI agent 都已自带 | 谁都能加 |
| 模型下载 + SSH 隧道 | 官方 Desktop + Comfy Manager | 官方主路径 |
| Electron 桌面版 | 官方 **Comfy Desktop** 1.1.8 beta（2026-11-02，登录可选） | 官方已占住"本地安装"这层 |
| 短剧成片管线 | SkyProduction / LTX Studio / Pika Short Film（都能"剧本直达成片"） | 三家已抢先 |

而"本地优先、开源、自带 ComfyUI"这个差异化——在**个人用户**身上恰恰是收不到钱的部分（Fooocus 54k★ 靠爱发电、SwarmUI 靠捐赠、InvokeAI 公司直接死掉）。

## 3. 你真正拥有的三样资产（不是代码行数）

### 资产 A：工作流 → 工具的适配层（`server/workflows/custom.ts`，565 行）
把任意 ComfyUI「导出(API)」的 JSON 拖进来，自动识别提示词/图像输入/种子/尺寸，变成画布上一个一键工具。
**为什么值钱**：官方前端锁自己的图，云产品锁自己的模型，**只有本地产品能做"模型无关"**。这一层不会随模型换代作废——它是对抗"平台每季度吞一层"的唯一结构。

### 资产 B：19,602 字的工艺知识库（`guides.ts` + `craft.ts`）
不是泛泛的 prompt 模板，是行业里少见的可执行规则：
- **关键帧必须是视频的第 0 秒**（动作在图里已经完成，视频里就没东西可演）——附正反例
- 视频提示词的固定结构（`integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music`），情绪词怎么换成身体动作
- 用 `silencedetect` 定位台词位置，按台词统一 **-16 LUFS**，环境声跟着调不被拉平
- 12 种题材的节拍/表演/拍法/声音，11 种画风的媒介与光色，稳定性预检（复杂运镜不和大动作挤一个镜头）
- 中文字幕拆分、`subtitles=false` 的取舍逻辑

**为什么值钱**：AI 短剧的成本结构是 token 40% / **人工调整 45%** / IP 10–15%——**钱花在"改"上，不在"生成"上**。这份手册正好长在 45% 那块。而且它模型无关：换 H3、换可灵、换 Wan，手册照样成立。

### 资产 C：可审计的 agent 管线（27 工具 + plan 审批 + GPU 时间确认 + rewind + 记忆）
"agent 能操作画布、重活前要你批准、每一步可回滚、成本可核算"——这是**本地唯一实现**。官方 Comfy Agent 只在 Cloud（本地版还写着 coming soon），云画布则天然按积分计费、按次卡人（社区里"取消订阅后积分被没收""Agent 跑到一半硬停"是现成的转化文案）。

## 4. 市场：哪条缝还开着（2026-11 事实）

### 还开着

**缝 1｜官方明确留白的两件事：本地 agent + 结果优先的画布。**
ComfyUI 在 2025–2026 的力气全花在节点图 DX（Subgraph、局部执行、2026-10 的 Nodes 2.0 用 Vue 重写渲染层）。**"我给你一个更好的节点编辑器"这条路已被官方焊死**。但官方的创作侧能力全部往 Cloud 账号收：Comfy Agent 仅 Cloud，Assets 面板在自托管要 `--enable-assets` + 数据库才有完整能力，筛选/ZIP/永久删除是云端独有。**官方没做"本地读画布→跑→把结果连回来源"这件事。**

**缝 2｜资产血统在本地是残废的。**
本地用户最真实的痛点是"几万张图找不回它的 prompt 和父图"，而官方把这块留给了 Cloud。这个项目**天生就是这个设计**（每个结果连线回输入）——但它现在只是一个好看的特性，不是一个可查询、可导出、可跨集复用的资产图谱。

**缝 3｜"无积分、无审查、可复现、能商用"的交付刚需。**
有明确证据的人群：商业交付方（版权/不过审/可复现）、有卡的重度玩家（会算电费账）、**被云端积分制度伤过的付费用户**（ComfyUI 官方 issue 里"积分作废""没订阅不能跑"的抱怨是现成的获客素材）、跑 agent 需要无限次试错的人。

**缝 4｜中文分发还有空位。**
Infinite-Canvas 停更腾出了"中文 + ComfyUI + 画布"的位置；英文区已被 ComfyArt（530★）/ Cubric / Promptus 占住但都不到 1k★。B 站/知乎/公众号的"本地部署 ComfyUI"内容仍在批量产出，**这是唯一还有教育红利的渠道**。

**缝 5｜合规是 2026 年新长出来的付费点。**
广电总局第 16 号令 **2026-09-01 施行**：分类备案、发行许可、**AI 内容逐集标识**、AI 素材版权核验，凡播必审。抖音 2026-08-03 上线成片预检工具（肖像/版权预检），红果 8 月启动 AI 脸治理、11 月上新剧分账规则。「一键出可过审的交付包」比「更好看的画布」值钱，而且**云平台没动力替你做**。

### 已经关上的门（别再投）

- ❌ 更好的节点编辑器（Nodes 2.0 已焊死）
- ❌ 通用"AI 画布"（Kosmik 8 年 / Playground / Cove 三具尸体）
- ❌ 单镜头生成（平台免费额度 + 视频生成已是红海：可灵 2026-03 ARR 近 5 亿美元、即梦 MAU 千万级）
- ❌ "剧本直达成片"的通用版（SkyProduction / LTX Studio / Pika Short Film 三家已做，且可灵 4.0 已内置时间线剪辑）
- ❌ 单镜头角色一致性（已被"参考素材数量"吃掉：可灵 4.0 = 15 项参考 + 10 张关键帧 + 30 秒；Seedance 2.5 = 50 项参考 + 30 秒；Higgsfield Popcorn 一次 8 张同角色场景）

### 必须知道的行业真相（决定你卖什么）
- 2026 年前 10 个月上线微短剧近 **55 万部**，其中 **>94% 是 AI**；但只有 **1.3% 摸到盈亏线、0.48% 破亿**。
- 跑量漫剧成本 **2,000–3,000 元/部**，精品 **500–1,500 元/分钟**；平台与投流吃掉 **82.5%**；万播分账从 30–100 元跌到 **5–10 元**；承制方从 1,216 家缩到 698 家（-42%），代工净利 **5–8%**。
- 观众侧在反噬：2026 春节档 AI 剧上线量是真人剧 50 倍、总播放只有 1/25；"AI 脸"话题 5,200 万阅读上热搜；2026-08「大批 AI 博主停更」上热搜，单集算力从 17 元涨到 80–100 元。
- **结论：不要淘金，卖铲子。** 卖给"必须靠交付活着、必须把返工砍一半"的承制方；不要指望靠自己的片子爆款分成。

## 5. 三条出路

### 路线 A（推荐）：从"画布"退到"制片后台"
**定位一句话**：你自己的 AI 制片车间——没有积分、没有审查、不按秒收费；每一帧连回它的来源，每一集都能返工，成片能直接交付。

- **只服务一类人**：短剧承制方 / 出海小团队（1–10 人）/ 电商素材团队。**不是**个人爱好者。
- **只留三个入口**：
  1. **导入工作流即工具**（资产 A，模型无关）
  2. **关键帧 → 镜头 → 成片**（资产 B 驱动，带稳定性预检、返工、响度/字幕）
  3. **血统与交付**（资产 C：资产图谱可查可导出 + 一键出"对白归一 + 中文字幕 + AI 标识"的交付包）
- **砍掉或降级**：MCP 推广、桌面打包优先、25 个模板砍到 3–5 个、中英双语打磨、通用画布的滤镜/搜索等长尾。
- **为什么是它**：这是唯一同时满足三件事的选择——你已有 19,602 字护城河；云平台的结构性弱点是"按次计费 + 审查 + 锁模型"；承制方真的在花钱。
- **死法**：30 天内做不出一条能过自己眼的 3 分钟成片，这条就是幻觉。

### 路线 B（备选）：ComfyUI 的"工作流即应用"层
把导入的 API 工作流一键变成可分享的小工具/页面，做生态里的 Streamlit；靠 ComfyUI Manager / registry 分发，不跟内容平台抢。
- **优点**：不淘金、卖铲子；分发靠生态；模型无关。
- **缺点**：官方 frontend 迭代极快（Nodes 2.0 用 7 个月吃掉了"更好的编辑器" narrative）；Promptus / WorkflowUI / ComfyArt 已占位；窗口在关。
- **死法**：官方把 subgraph + 分享做了，或者生态不给流量。

### 路线 C（诚实的退路）：收摊，把资产变成内容
把 19,602 字工艺手册开源成独立 skill 包；把工作流适配层抽成库；写一份《AI 短剧真实成本与返工率》报告。
- **收益**：建立个人品牌和分发能力——这是独狼开发者最缺、也最保值的资产。上限低，但不浪费。
- **对独狼来说，这条路经常比"硬做一个没人知道的产品"回报更高。**

### 推荐组合
**A 为主线，C 的内容动作当作 A 的获客手段（不冲突），B 只在 A 的第一道闸门失败后启动。**

## 6. 路线 A 的执行方案：头 14 天几乎不写代码

### 第 0–1 天：先让它"存在"
1. **公开仓库**（现在是私有，对外 404 = 等于没做过）。改掉 `infinode@invalid`，用真人身份。
2. **README 从 367 行砍到 60 行**：一句话 + 30 秒视频 + 三个截图 + 一条安装命令。现在这份 README 把 25 个模板、SSH 隧道、MCP、模型许可证全铺开，读者第一屏就该看到"这是什么、凭什么用"。
3. 一句话定位贴在仓库顶部（见上）。

### 第 1–3 天：跑通那条从未跑通的链路（Gate 1）
4. 端到端做一条 **60 秒片**：剧本 → 分镜 → 设定图 → 关键帧 → 每镜头视频 → `assemble_video`。
   这一步会暴露 3,000 行未验证代码里的全部坑。**如果三天做不出来，答案就已经有了**——直接转 B 或 C。
5. 记下真实数字：总耗时、`inspect_clips` 误判次数、返工镜头数、电费/API 成本。

### 第 3–5 天：把"手册"变成"硬校验"（这是护城河唯一能被感知的形态）
6. 把三条关键工艺从"给 agent 看的文档"改成"程序强制"：
   - 关键帧必须是视频第 0 秒（提交前校验首帧与提示词的一致性描述）
   - 每段视频提交前必须过稳定性预检（复杂运镜 × 大动作 = 拦下）
   - 成片必须过对白响度/字幕完整性检查，不合格不给导出
   **理由**：agent 手册谁都能抄，校验不通过就交不了片，抄不走。

### 第 5–7 天：做一个能传播的物件
7. 录一条 **8 分钟实操视频**：一句话 → 60 秒成片，**保留失败和返工的片段**，结尾公布真实成本与耗时。
   行业里没人公开真实返工率——这就是你最好的获客内容。

### 第 8–12 天：三处分发（一次做完，不要分散）
8. B 站（长视频 + 教程位）、小红书/即刻（结果切片）、Reddit `r/comfyui` + ComfyUI GitHub Discussions（英文一段话 + 30 秒 GIF）。
   文案主轴：**没有积分、没有审查、不按秒收费、跑在你自己的卡上、每一帧可追溯**。

### 第 13–14 天：收窄
9. 只留三个入口；MCP/桌面/模板库降级为"可选"；给一个"跑通了"的一键脚本或 Docker。

### 三道闸门（决策规则，写下来照着执行）

| 闸门 | 时间 | 通过条件 | 不通过就 |
|---|---|---|---|

### 变现（按现实锚点定，不要按理想定）
- **不要卖软件许可证**：Kosmik 8 年死、InvokeAI 公司死、SwarmUI 靠捐赠、Fooocus 靠爱发电。
- 两条活法：
  1. **交付/定制服务，3,000–30,000 元/单**。承制方缺的是"把返工砍一半的人"，不是又一个工具。
  2. **开源核心 + 商业版**（团队协作 / 跨集资产库 / 多机调度 / **过审预检与 AI 标识交付包**），B 端 **300–2,000 元/席/月**。可灵黑钻 4,049 元/月、即梦 5,199 元/年、LTX 商用门槛 $35/月已经把这个价格带教育过了。

## 7. 风险登记（按可能性排序）

1. **沉默死（最高）**：独狼 + 零分发，最可能的结局不是被竞品打败，是没人知道。**头 14 天 70% 的时间必须花在"给人看"，不是"给代码加行"。**
2. **平台每季度吞一层**：可灵 3.0→4.0 只用了 7 个月（15 参考 + 10 关键帧 + 30 秒 + 时间线），Seedance 2.0→2.5 六个月（50 参考 + 30 秒）。→ **只做模型无关的编排与资产层；把"换模型不换人设"做成卖点**，这也是唯一能对抗模型换代的结构。
3. **剪刀差：省下的钱不归客户**（万播分账 5–10 元、平台投流占 82.5%）→ **卖给"要交付"的人，不要卖给"要爆款"的人**。
4. **画布品类本身的判决**（Flowise 55k★ 归档的二手分析原话是"the canvas was optional"）→ **永远不要把画布当卖点，把它当界面**。
5. **未验证代码的雷**：3,000+ 行短剧管线从未跑通，`assemble_video` / `inspect_clips` / 响度归一都可能是纸面功能。→ Gate 1 必须在三天内把雷全部踩掉。
6. **单人产能天花板**：一个人做全栈产品 + 内容分发 + 运营 = 不可能。→ 选"小切口 + 高单价 + 少数客户"，不做 C 端 SaaS。
